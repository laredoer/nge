# 关节和 2D 刚体带动 3D 模型

> 前置：2D 物理（[physics2d.md](physics2d.md)）、2.5D 相机（[camera25d.md](camera25d.md)）、调试绘制（[gizmos.md](gizmos.md)）。

## 目标

2D 物理只有一个个独立的刚体：做不了吊桥、链子、门的合页、车轮、弹簧板。2.5D 的 3D 模型也只能摆在固定位置自己转，不能被撞、被推。

**验收标准**：
- TSX 的 `scene.joints` 按精灵 id 把两个刚体（或一个刚体和世界）连起来，五种：焊死（fixed）、转动（revolute，可限角度、带马达）、滑动（prismatic，可限范围、带马达）、绳子（rope）、弹簧（spring）。
- 精灵后出现、删掉、换了声明的位置，关节跟着连上、拆掉、重算锚点；刚体重建（换了种类或形状）后自动重连。
- 模型节点写 `attach: "精灵 id"`，跟着那个精灵画的位置和角度走（有刚体时是插值过的位置），x、y、z 和 `rotation` 成了相对精灵的偏移。
- 物理调试视图（Q）画出关节。
- 平台跳跃：一串用转动关节连起来的铁链吊着铁球甩，角色能撞它、站在球上；终点前的 3D 箱子能推着走、跳上去。

## 做法

### 引擎（`nge-physics2d`）

```rust
commands.spawn(Joint {
    a: Some(door_frame), b: door,
    kind: JointKind::Revolute { limits: Some([0.0, FRAC_PI_2]), motor: None },
    anchor_a: Vec2::new(10.0, 0.0), anchor_b: Vec2::new(-30.0, 0.0),
    angle: 0.0, collide: false,
});
```

- **组件**：关节挂在单独的实体上。`a` 是 `None` 时连到世界（物理里一个固定在原点、没有碰撞体的刚体，用到时才建，`Physics::len` 不算它）。
- **锚点**：`anchor_a` / `anchor_b` 在各自刚体的坐标里。`angle` 是 b 相对 a 的角度：焊死和滑动关节保持这个角度，转动关节的 `limits` 从这里算起。
- **种类**：
  - 焊死、转动、滑动用 rapier 对应的关节，两个锚点坐标系的朝向差就是 `angle`；滑动关节的轴是锚点坐标系的 x 轴，按 `axis`（a 的坐标里）转过去。
  - 绳子、弹簧只管距离，不管角度。弹簧用加速度模型：`stiffness`、`damping` 和质量无关（挂着的东西停在静止长度往下 g / k 的地方）。
  - 马达是速度马达，跟速度的增益固定（1000），`max_force` 默认不限。
- **同步**：新系统 `joint::sync` 排在建刚体之后、走物理之前，每帧对一遍：
  - 关节组件没了（去掉或实体删了）就拆掉。
  - 两头还不是刚体时先不连，成了刚体再连。
  - 声明变了：两头没换时原地换参数（每帧改马达速度不丢求解器攒下的冲量），换了两头就拆了重建；rapier 删刚体时会顺带删关节，这时句柄失效，也重建。
- **参数检查**：不是有限的数、绳长不是正数、弹簧参数是负数、范围下限大于上限、转动范围超过一整圈（rapier 里等于不限）、滑动轴是 0、两头是同一个刚体，都 warn 一次不连；记着这份声明，改了再试。
- **两个刚体之间的碰撞**：默认关（和 rapier、Box2D 一样，连着的东西一般会重叠），`collide: true` 打开。
- **调试视图**：连上了的关节画一条线连两个锚点，锚点各一个小圆（粉色）。
- `Physics::joints()` 是建好的关节数，`Physics::is_linked(entity)` 看某个关节连上没有。

### 场景（`scene.joints`）

```ts
joints: [
  // 单摆：b 绕世界上的 (0, 200) 转
  { id: "pendulum", b: "bob", kind: "revolute", anchorA: [0, 200] },
  // 带马达的车轮
  { id: "wheel", a: "car", b: "wheel-l", kind: "revolute", motor: { speed: -360, maxForce: 5e6 } },
  // 弹簧板
  { id: "spring", b: "pad", kind: "spring", anchorA: [300, 0], length: 40, stiffness: 300 },
]
```

- **坐标**：锚点和轴都写世界坐标，按两头精灵**声明的**位置和角度换到各自身上；`angle` 取两个精灵声明的角度差。精灵被物理挪走以后才加的关节，锚点还是按声明的位置算。
- **锚点的默认值**：
  - 焊死、转动、滑动只有一个支点：只写 `anchorA` 或 `anchorB` 时两头都用它，都不写是 b 的位置。
  - 绳子、弹簧两头各一个：`anchorA` 不写是 a 的位置（连世界时必须写，不然 warn 不连），`anchorB` 不写是 b 的位置。
  - `length` 不写时是两个锚点声明时的距离。
- **单位**：转动关节的 `limits` 和马达速度用度、度 / 秒；滑动关节用 point、point / s。弹簧的 `stiffness` 默认 100、`damping` 默认 10。
- **找精灵**：`resolve` 系统每帧按 id 找带 `body` 的精灵，算出 `Joint`，和现有的不一样才写：
  - 精灵后来才有、删掉了、换了声明的位置，都跟着改；
  - 找不到（或没有 `body`）、连世界的绳子没写 `anchorA` 时 warn 一次，连上以后再出问题再 warn。
  - 单支点的关节同时写了 `anchorA`、`anchorB` 又不相等时不提示，开局两个锚点会被猛地拉到一起。
  - 它在物理之前跑，精灵和关节在同一份场景里出现时当帧就连上。
- **字段写错**：`kind` 写错、多了不认识的字段，整份场景解析失败（只记 warn），免得拼错的 `lenght` 被悄悄忽略。
- 关卡切换时关节和精灵一起删掉重建。

### 模型跟着精灵（`attach`）

```ts
sprites: [{ id: "crate-body", x: 2352, y: 56, w: 40, h: 40, color: "#00000000", body: { density: 0.3 } }],
models: [{ id: "crate", model: "asset:/@platformer/crate.glb", attach: "crate-body", scale: 40, rotation: [20, 0, 0] }],
```

- 物理一步之后摆模型：位置是精灵画的位置（有刚体时是插值过的 `DrawAt`）加上转过的 `(x, y)` 偏移，z 是节点的 `z`；角度是绕 z 轴转精灵的角度，再乘上节点的 `rotation`。
- 一般和 `camera3d.match2d` 一起用，3D 的一个单位就是 2D 的一个 point。
- 精灵不存在时模型留在原地：一开始就没有时在声明的 x、y、z（当世界坐标），跟过以后精灵删了就停在最后的位置。
- `spin` 和 `attach` 一起写时 warn，`spin` 不生效。
- 名字牌（文字的 `follow`）排在 `attach` 后面，跟得上当帧的位置。

### 平台跳跃

- **铁链**：`levels.ts` 的 `swingAt(x, y)`：4 节 6 × 18 的链子（密度 0.5）和一个半径 10 的铁球（密度 2，一开始往右 150 的速度），每个连接点一个转动关节，第一节挂在世界上。第一关挂在起点右边，第二关挂在第一个坑上面，第三关在 Tiled 地图的对象层里用 `swing` 点标支点。
- **箱子**：`crate` 变成一个看不见的 40 × 40 动态刚体（密度 0.3）加一个挂在上面的箱子模型，往后仰 20°，不再自己转。角色撞上去会推着它走，能跳上去站着。
- 按 R 重来、掉坑重生时铁链和箱子不复位（节点没变，同步不碰）；箱子推进坑里以后要换关才回来。

## 不做

- 关节断裂（受力超过多少就断）、关节的受力读数。
- 多体关节（rapier 的 multibody，长链子更稳）：4 节的链子挂重 12 倍的球，两秒后连接点误差在 2 point 以内，够用。
- 位置马达（转到某个角度停住）、弹簧的最大长度。
- 3D 模型带碰撞体、3D 物理。
- 模型跟着瓦片地图或者别的模型走。

## 验收

- `nge-physics2d` 新增 21 个：
  - 单摆绳长不变、锚点按各自刚体的坐标、转动关节的角度范围和马达；
  - 焊死一起走、焊死保持声明的角度、滑动关节沿轴滑并停在范围边上、滑动马达（轴会归一化）、滑动关节的 `angle` 只转刚体不转轴；
  - 绳子松着时自由下落、拉直后挂住，弹簧停在静止长度往下 g / k；
  - 去掉关节组件或删掉关节实体就拆掉，改了声明就重建；
  - 刚体后出现才连、刚体重建后重连、刚体删了关节也没了；
  - 坏参数不连（每一项检查都有对应的输入），改对了就连上；只改马达速度时原地更新；
  - 转动关节的范围从声明的角度算起，挂在转过的 a 上的滑动关节沿转过的轴滑；
  - 连着的两个刚体默认不碰、`collide` 打开后会碰；
  - 调试视图只画连上了的关节，线从一个锚点连到另一个。
- `nge-scene` 新增 8 个：
  - 单摆；锚点、轴、角度、度换弧度、默认值按声明的位置换算；
  - 精灵后出现、没有 body、删掉、换了声明的位置，关节跟着改；
  - 连世界的绳子不写 `anchorA` 不连；拼错的字段和种类解析失败；
  - 平台跳跃那样的重链子甩两秒不散；
  - 模型跟着掉下去、转起来的刚体（插值过的位置、偏移跟着转、z 不变、先按声明转再跟着精灵转），精灵不存在时留在原地、去掉 `attach` 就不跟。
- 平台跳跃的 TS 测试：每关的铁链一节节挂着，连接点在上一节的底边；箱子模型挂在动态刚体上；第三关从 Tiled 读出支点。
- 关节和 `attach` 的代码都做了变异检查，改掉参数检查、坐标换算、生命周期的分支都有测试报错；坏参数「只 warn 一次」靠记下被拒的声明，测试看不到日志，没覆盖。
- 还没手测：平台跳跃里铁链甩起来的样子、撞上去和站在球上的手感，推箱子、跳上箱子，按 Q 看关节的线。

## 修过的问题

- 参数不对的关节每帧都 warn：物理层没记下被拒的声明，下一帧又校验一遍；场景层连世界的绳子没写 `anchorA` 的 warn 也没去重。现在物理层记着被拒的声明，声明不变不再试；场景层所有失败原因都走同一个去重。参数也改成先校验、再建连世界用的固定刚体。
- 有几项参数检查（马达、范围上下限、弹簧参数）没有测试输入，转动范围从 `angle` 算起、挂在转过的 a 上的滑动关节两种组合也没测，都补上了。
- 转动范围超过一整圈时 rapier 当成不限，原来悄悄放过，现在当坏参数。
- 改一下马达速度就把关节拆了重建，丢掉求解器的热启动：两头没换时原地换参数。
- 文档说精灵不存在时模型回到声明的位置，其实跟过以后是停在最后的位置，改了文档。
