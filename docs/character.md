# 角色控制器：走斜坡、上台阶、贴地、被平台带着走

> 前置：2D 物理（[physics2d.md](physics2d.md)）、移动平台（[moving-platforms.md](moving-platforms.md)）。

## 目标

平台跳跃的角色现在是一个没有摩擦、锁住旋转的动态刚体，游戏自己改速度。这样有几个毛病：

- 站在横移的平台上要自己把平台的速度加进去。
- 下坡时会飞出去，斜坡和台阶都没法走。
- 撞墙时会被求解器弹一下。

**验收标准**：
- 引擎提供角色控制器：游戏只给速度，引擎负责重力、贴地、沿墙滑、爬不超过一定角度的坡、自动上矮台阶，以及被脚下的平台带着走（横着、竖着都行）。
- 能推开动态刚体（箱子），会被敌人这类 kinematic 物体挡住、碰到，碰到的东西照样出现在 `Physics::contacts` 里。
- 平台跳跃的角色换成角色控制器，原来的手感测试都过。

## 做法

### 组件（`nge-physics2d`）

- `Character { max_slope, step, snap, gravity_scale }`，默认 50° / 0（不自动上台阶）/ 4 / 1。
  - 要和 `RigidBody::Kinematic`、`Collider`、`Velocity` 一起用。
  - 底下用 rapier 的 `KinematicCharacterController`。
- 每个物理步：
  1. 速度先加上重力乘以 `gravity_scale`（站在地上、没在往上走时不加）。
  2. 先跟着脚下的东西走它这一步的位移（查碰撞时不算它自己，它还没挪）。
  3. 自己走速度 × 步长，从原地算（相对脚下的东西）。控制器沿墙、沿坡滑，碰到挡住的就停，贴地距离以内的往下贴。
  4. 两段位移加起来设 kinematic 的下一个位置。
  5. 改速度：落地后往下的速度清零，顶到天花板时往上的速度清零，撞墙（比 `max_slope` 陡）时朝墙的水平速度清零。
  6. 碰到动态刚体时，按角色的质量给它冲量（rapier 的 `solve_character_collision_impulses`）。
- 走完所有的步之后，用角色的形状往外扩 `CONTACT_GAP`（2）查一遍贴着的碰撞体，算出接触的法线。
  - 这份接触替代 rapier 自己的接触对，因为 kinematic 和 kinematic、kinematic 和固定碰撞体之间 rapier 不算接触。
  - `Physics::contacts` 对角色返回它；脚下的东西（法线朝上、坡度不超过 `max_slope`）在下一帧用来带着走。
- 游戏直接改角色的 `Transform2d` 是瞬移（比如重生），不从旧位置滑过去。

### 场景

- `body.kind: "character"`，参数 `slope`（度）、`step`、`snap`。

### 示例（平台跳跃）

- 角色换成 `kind: "character"`。
- `control` 去掉自己加平台速度的那一段：引擎会带着走。
- 第一关加一段 30° 的斜坡（几块斜着的实心矩形不行，要真的斜面）；原来在那儿的敌人挪到后面。
  - 瓦片地图只有方格，斜坡用一个转过角度的固定刚体精灵。

## 不做

- 3D 角色控制器（做 3D 物理时再说）。
- 单向平台（从下面跳上去）。
- 角色之间互相推；别的角色也不当脚下的地面带着走。
- 横着动的 kinematic 物体（平台的侧面、敌人）撞上角色时不把它推开：rapier 的控制器只在角色不动时才把它从别的东西里挪出来。要被推开的游戏自己给角色加速度。
- `Character` 只对 kinematic 刚体起作用，挂在别的刚体上不管。
- 改了碰撞体（形状、大小）时角色的状态重新开始：这一帧不算贴着地，也不跟着脚下的东西走。
- 陡坡（四十多度以上）的坡脚和地面齐平时是个尖角，rapier 会把它当墙挡住；陡坡的坡脚往地里埋一点。

## 验收

- `nge-physics2d`：
  - 落地停住；走斜坡上去、下来都贴着地；太陡的坡爬不上。
  - 自动上台阶，台阶高了上不去；撞墙速度清零；顶到天花板往上的速度清零。
  - 被横移、上升、下降的平台带着走；推得动箱子。
  - 碰到 kinematic 的敌人有接触，法线对；瞬移不插值、不再跟着原来的平台走；速度是 NaN 时清零。
  - 跟着平台走进墙时停在墙前；旁边上升的墙不带着走。
- 场景：`kind: "character"` 建出角色控制器。
- 平台跳跃：原来的测试全过，加一个走上斜坡的测试。重生、重开后的位置容差从 0.1 放宽到 0.5：控制器和地面之间留着一点间隙，站稳的位置比起点高一点。
- 变异检查：重力、落地 / 天花板 / 撞墙清零、带着走（按这一步的位移、只跟脚下的）、推箱子、接触的法线和间隙、上台阶、贴地、参数跟着组件、碰 sensor、场景的种类和角度换算，改掉都有测试报错。
  - 只改爬坡角、不改下滑角：太陡的坡照样滑下来，结果一样。
- 还没手测：手感。

## 修过的问题

- 撞墙后速度没清零：rapier 碰撞结果的法线是从对方指向角色的，取反了。
- 被平台带着走时慢两步：用的是平台上一帧的速度；改成平台这一步的位移。
- 往下走的平台带不动角色：平台这一步还没挪，跟着往下走时撞上平台自己。改成先单独跟着平台走（不查脚下的平台），自己走的那段相对平台算。
- 比 45° 陡、但没超过 `max_slope` 的坡被当成墙，速度清零爬不上去；撞墙改成按 `max_slope` 算。
- 站在往右走的平台上同时往右走，会插进前面的墙里：跟平台走和自己走两段都从原地查碰撞，到墙的间隙算了两次。改成先自己走，再从走到的地方跟着平台走。
- 判断撞墙、顶天花板时又把法线转了一遍角色的角度（rapier 给的已经是世界坐标），角色带角度时会判断错。
- 瞬移离开移动平台后，下一步还被原来的平台带一段；瞬移时清掉脚下的东西。
- 速度变成 NaN 后一直是 NaN，角色冻住；改成清零。参数不是有限数时用默认值。
- 角色碰不到金币、终点这些 sensor：rapier 默认不算 kinematic 和固定碰撞体之间的重叠；角色的碰撞体打开全部类型。
