# 性能面板：帧率、各段耗时、draw call、实体数

> 前置：文字（[m5-extensions.md](m5-extensions.md)）、TSX 场景（[m3-tsx.md](m3-tsx.md)）。

## 目标

觉得卡的时候，现在只能临时往帧循环里加探针。引擎每秒发给 NSH 的 `fps` 事件只有帧率和最长帧间隔，看不出时间花在了哪里：是系统跑得慢、录渲染命令慢，还是在等垂直同步、等系统交帧。nsh 自带的 FPS 监视器测的是 NSH 界面那一层，测不到引擎线程。

**验收标准**：
- 引擎自己记下每帧各段花的时间，以及这一帧发了几次 draw、画了多少个实例、有多少实体。
- 左上角可以开一个面板，每半秒更新一次。TSX 写 `scene.perf`，Rust 写 `PerfOverlay`。
- 平台跳跃按 P 开关。

## 做法

### 测量（`nge-core`）

- 帧循环每帧量四段，画完后通过 `Game::timing(FrameTiming)` 交给游戏（默认什么都不做）。
  - `frame`：和上一帧画完时隔了多久。
  - `update`：处理 NSH 发来的消息（场景 JSON 的解析等）加上 `Game::update`。
  - `render`：`Game::render` 加提交。
  - `wait`：拿下一张画面，加上交给系统显示，通常是在等垂直同步。
- 拿不到画面的帧不报。开头的第一帧、暂停后的第一帧、拿不到画面（比如拖窗口改大小）之后的第一帧没有上一帧可比，也不报（`FrameClock`）。
- `Game::timing` 自己花的时间（数实体等）算在下一帧的间隔里，不归任何一段。

### 汇总（`nge-ecs` 的 `perf.rs`）

- 资源 `Perf`：每满半秒（`PERF_WINDOW`）出一份 `PerfReport`。
  - 帧率、平均帧间隔、最长帧间隔。
  - 更新、渲染、等待各自的平均毫秒数。
  - draw call、实例数、实体数：取窗口里最后一帧的。
- 分段的时间不是有限数、是负数的当 0；帧间隔坏了的这一帧整个不算。
- 实体数要把所有实体数一遍，只在出汇总的那一帧数。
- `RenderFrame::count(draws, instances)`：渲染器每帧记下自己发了几次 draw、画了多少个实例，每帧开头清零。
  - 精灵：每批一次，实例是精灵（包括 `repeat` 铺出来的每一份）和额外实例（粒子、调试线）的总数。
  - 3D：每个部件一次，开着阴影时阴影 pass 再算一遍；实例是部件数。
  - 文字：glyphon 把所有字合成一次 draw，实例是字段数。
  - 后处理：每一遍一次，没有实例。
- 实体数不算资源（bevy 里资源也是实体），算 observer 这类 bevy 自己的实体，不算 `Disabled` 的。
- 面板自己是一段屏幕文字：打开后实体数、文字的实例数各多 1，没有别的文字时 draw 也多 1。

### 面板（`nge-text` 的 `perf.rs`）

- 资源 `PerfOverlay(bool)`，默认关。开着时在左上角 (8, 8) 放一段 12 号的淡绿色屏幕文字（`PerfText`）。
  - 还没满一个窗口时写「性能统计中…」。
  - 汇总没变时不重新拼字、不改文字，免得每帧重新排版。
- 面板一共三行：
  ```
  60 fps  帧 16.7 ms（最长 21.3）
  更新 1.2  渲染 2.5  等待 13.0 ms
  draw 42  实例 1830  实体 312
  ```

### 场景和 TSX

- `scene.perf?: boolean`：只在声明变了的时候写 `PerfOverlay`，所以 Rust 自己开关的不会被每帧的同步覆盖；去掉声明就关。

### 示例（平台跳跃）

- 按 P 开关（Rust 的 `toggle_perf`），界面上的按键提示加了「P 性能」。

## 不做

- GPU 时间（时间戳查询）。现在的「渲染」只是 CPU 录制和提交命令的时间，GPU 真正画了多久要用时间戳查询，有的设备不支持。
- 曲线图、按系统细分的耗时。
- 把汇总发给 NSH。现有的 `fps` 事件保持原样。

## 验收

- `nge-core`：帧间隔在开头和断开（暂停、拿不到画面）后的第一帧没有，之后照常。
- `nge-ecs`：
  - 满半秒出汇总（平均值对，draw call 等取最后一帧的）。
  - 卡了的那一帧是最长帧，下一个窗口重新算。
  - 坏的分段当 0，帧间隔坏了的那帧不算。
  - 实体只在出汇总时数一次；刚出完汇总的下一帧汇总不变。
  - `EcsGame` 把帧时间和这一帧的计数、实体数（不算资源）记进 `Perf`。
  - 渲染器的计数累加，下一帧清零。
- 离屏渲染测试：
  - 精灵每批一次、背景层另算。
  - 3D 每个部件一次，开着阴影翻倍。
  - 两段字一次 draw。
  - 两遍后处理加一个精灵是 3 次。
- `nge-text`：面板的三行字；开关时出现和消失，跟着汇总改字，只有一个。
- `nge-scene`：`perf` 只在声明变了时写，Rust 关掉后场景没改就不再打开，去掉声明就关。
- 平台跳跃：按 P 打开，场景每帧同步也不会关掉，再按一次关掉。
- 变异检查：
  - 改掉以下任何一处都有测试报错：窗口的判断、平均值、最长帧、窗口重置、坏时间的处理、各渲染器的计数、计数清零、实体数不算资源、面板的开关和改字、场景的同步、P 键。
  - 帧循环里各段的测量要有 surface，没有自动测试；帧间隔的取法抽成了 `FrameClock` 单独测。
- 还没手测：平台跳跃里按 P 看面板，各段的数字在 Mac 和 iPhone 上合不合理。

## 修过的问题

- 实体数每帧都要把所有实体数一遍，面板关着也数；改成只在出汇总时数。
- 处理 NSH 消息（解析场景 JSON）的时间不归任何一段，帧间隔比各段加起来多一截却看不出花在哪；改成算进「更新」。
- 拿不到画面的空转被并进下一帧的间隔，拖窗口改大小时最长帧跳到上百毫秒；改成这之后的第一帧不报。
- 帧间隔是 NaN 的帧当成 0 还照样计数，帧率偏高；改成整帧不算。
- 面板开着时每帧都拼一遍字；改成汇总变了才拼。
