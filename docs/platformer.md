# 平台跳跃示例

> 前置：键盘（[keyboard.md](keyboard.md)）、相机（[camera.md](camera.md)）、瓦片地图（[tilemap.md](tilemap.md)）、2D 物理（[physics2d.md](physics2d.md)）。

## 目标

`examples/platformer`：一张 80 × 15 格的关卡，← → / A D 跑、空格 / ↑ / W 跳（手柄：十字键 / 左摇杆跑、A 跳），吃金币、躲坑、踩敌人，碰到终点旗子通关；起跳、踩敌人、吃金币、掉坑、通关有音效，R（手柄菜单键）重新开始。关卡、金币、终点、相机全部在 `App.tsx` 里声明；每帧的角色控制写在 Rust 里（引擎的分工：TSX 不跑每帧逻辑）。

**验收标准**：Mac 上能从起点玩到终点：相机跟着角色、到关卡两头停住；能跳上平台和台阶；掉进坑回到起点，HUD 记次数；金币吃掉就消失并飘「+1」，HUD 计数；碰到终点 HUD 显示用时；五种音效都响；按 R 回到起点，金币、掉坑次数、用时都重来；踩到敌人它消失、角色弹起来，从侧面碰到敌人回到起点，R 以后敌人回来。

## 物理层新增

### `Physics::contacts(entity) -> Vec<Contact>`

`Contact { other: Entity, normal: Vec2 }`：上一步结束时这个实体的碰撞体正在接触的碰撞体，`normal` 是从对方指向自己的单位向量（站在地上时是 `(0, 1)`，贴着左边的墙是 `(1, 0)`）。只算交给求解器的接触点（含很近还没碰上的预测点，「着地」会提前零点几个 point），sensor 的重叠不算；实体还没建到物理里时是空的。`other` 是碰撞体所在的实体：碰到瓦片地图时是地图下面的碰撞体子实体，要找地图得经过 `ChildOf`。角色控制用它判断「脚下有地」（`normal.y > 0.7`），墙的法线是水平的，所以贴着墙不能跳。

### `LockRotation` 组件 / `body.fixedRotation`

锁住刚体的旋转，碰撞不会让它转起来；加锁时原来的角速度也清零（rapier 只把转动惯量当无穷大，不管已有的角速度）。加上、去掉都在下一次物理同步时生效（去掉时把 `RigidBody` 标成变了，`create` 里解锁），不重建刚体。TSX 精灵的 `body.fixedRotation: true` 对应这个组件。

## 角色控制（`examples/platformer/src/lib.rs`）

- 按 id `player` 找到角色精灵，每帧在 `Update` 里改它的 `Velocity`（物理在 `PostUpdate`，这一帧就生效）。
- 水平：朝 `axis(←/A, →/D) × 260` 加速，地上 3000、空中 1500 point / s²。
- 跳：起跳速度 640（场景重力 1800，整跳大约 114 point，3 格半）；走出平台边 0.1 秒内还能跳（土狼时间），落地前 0.12 秒内按的跳也算（跳跃缓冲）；上升时跳跃键全松开了速度减半，轻按跳得矮；靠缓冲起跳时键已经松开就直接按短跳。
- 着地 = 有一个接触的法线 `y > 0.7`，且相对脚下那个东西的竖直速度 ≤ 1：刚起跳那一帧之后还可能有地面的预测接触点，往上走时不算着地，免得一次按键跳两下；站在上升的平台上照样能跳。
- 时间缩放为 0（暂停）或帧时间不是正数时整个控制不动：暂停中按的键不会留到继续以后。
- 脚下的东西按 `contacts` 里法线朝上的找，速度用 `Physics::velocity`（地图的碰撞体没有速度，按 0）；同时踩着地面和平台时取动得快的那个。站在横移的平台上时水平目标速度加上它的水平速度，跟着平台走。
- 掉到 y < −400：送回第一次见到角色的位置，速度清零，土狼时间和跳跃缓冲也清掉（掉坑前按的跳不留到起点），发 `respawn { falls }` 给 TSX。
- 按 R / 手柄菜单键：见下面「音效和重新开始」。这一分支在暂停保护之后、其他输入之前：暂停时按的不算，和起跳同一帧时只重来。
- 关卡的 `friction` 是 0：角色的水平速度由控制决定，地面摩擦只会让最高速度比设定的低。

## TSX（`examples/platformer/App.tsx`）

- 关卡用一个 `tileAt(列, 行)` 函数生成 `data`：两头石墙、一行草地带三个坑、六块木平台、一段石台阶。坑边正上方不放平台（角色 32 高，平台底边低于 96 时从地面起跳会撞头掉坑）。
- 两块移动平台（见 [moving-platforms.md](moving-platforms.md)）：第三个坑加宽到 6 格，上面一块左右来回；第二个坑里一块上下来回，把角色送到高处的金币 `coin-v`（放在坑里，降下来时底下没有地面，不会把人压进地里）。都是 kinematic 精灵，挂上时 `ref` 里各发一条 `repeat: -1, yoyo: true` 的补间（没写 `from`，来回的范围从平台当时的位置算，所以只在挂上时发一次）。
- 金币是 `sensor` 的固定刚体；角色的 `body.collide` 开着，所以穿过金币时发 `collide`，TSX 把它从列表里去掉、`floatText` 飘「+1」。终点也是 sensor。
- 相机 `follow: "player"`，`bounds` 是整张关卡（下面多留 160 让坑看得见）。

## 音效和重新开始

后来补的（原来写在「不做」里），让示例成为一个完整能玩的小游戏。

- 声音都是 `examples/platformer/tools/make_sounds.py` 合成的 wav（不从网上下载）：`jump`（往上滑的短音）、`stomp`（往下滑的短音）、`coin`（两个音的「叮叮」）、`fall`（往下滑）、`win`（上行琶音）。
- 跳、踩敌人和掉坑发生在 Rust 的控制里，就在 Rust 里放：启动时加载 `jump` / `stomp` / `fall`，起跳那一帧放 `jump`（同一帧踩到敌人时只放 `stomp`），送回起点时放 `fall`。
- 吃金币和通关是 TSX 判断的，就在 TSX 里发 `sound` command；`scene.audio.preload` 预先加载 `coin` / `win`，第一次吃金币不用等解码。
- 按 R（或手柄的菜单键 `GamepadMenu`）重新开始：Rust 的控制把角色送回起点、速度清零、整个控制状态清零（包括掉坑次数），发事件 `restart {}`；TSX 收到后把金币放回去、清掉通关时间、重新计时。踩掉的敌人回来；移动平台和敌人的巡逻不动（它们一直在来回）；正在放的声音（比如通关的琶音）放完为止，重来本身不出声。
- R 在 `captureKeys` 的默认名单里（字母键），不用另外写。
- 用时是墙钟时间，不扣暂停（示例本身没有暂停键）。
- 每个音末尾淡出 5 ms，免得截断处「咔哒」一声。

## 敌人

- TSX 里 id 以 `enemy-` 开头的精灵是敌人：kinematic 刚体，挂上时发一条 `repeat: -1, yoyo: true` 的补间来回巡逻（和移动平台一样）。
- Rust 的控制按 `contacts` 看角色碰到的敌人：
  - 法线朝上（`y > 0.7`，角色在上面）是踩到：角色弹起来（按着跳跃键弹 `JUMP`，没按弹一半），发 `stomp { id, x, y }`（`x` / `y` 是角色当时的位置，TSX 在那里飘字；敌人在巡逻，TSX 只知道它的起点），放 `stomp` 音效。
  - 别的方向是被撞到：和掉坑一样送回起点，`falls` 加一，发 `respawn`，放 `fall` 音效。HUD 上「掉下去」改成「失手」。
  - 同一只敌人和角色只有一个接触，不会既踩到又被撞到；同一帧踩到一只、被另一只撞到时照样送回起点。
  - 斜着落到敌人的角上、只重叠一两个 point 时法线可能是水平的，算被撞。
- 踩到的敌人 TSX 不从场景里删，改成没有刚体、透明（实体还在，巡逻补间接着走）；R 重新开始时恢复刚体和颜色。这样不用在重新出现时补发补间。Rust 在 TSX 去掉刚体之前（中间隔一两帧）记着已经踩过的，不重复发 `stomp`、也不算被撞（这一两帧里它像一块普通的平台）；掉坑、被撞送回起点时还记着，按 R 时清掉。nge-scene 有测试保证去掉、加回刚体时补间接着走。
- 关卡里放三只：第一个坑前的地面、第一个和第二个坑之间的地面、终点前的地面，各匀速巡逻 3 格（1.5 秒走一趟）。

## 调试视图（Q）

按 Q 开关（`src/debug.rs`，用 [`Gizmos`](gizmos.md) 画）：所有碰撞体的轮廓（`PhysicsDebug`：地面灰、角色和敌人按刚体种类上色、金币是黄色的 sensor），加上角色往面向的方向、往下各发一条射线（红线到交点，黄点是交点，绿线是法线；没碰到时是淡红色），身边一个蓝框标出重叠的金币、敌人、平台（含 sensor，不含自己；地图的碰撞体没有画面位置，不标）。查询用物理的真实位置，画的时候加上角色画面插值的偏移，和角色贴着。演示 [physics2d.md](physics2d.md) 的空间查询用，不影响玩法。

## 不做

- 会掉下平台 / 追人的敌人、敌人之间的碰撞、关卡切换、存档、背景音乐：需要时再加。
- 暂停时松开跳跃键：控制在暂停时不跑，那一帧的「松开」丢了，继续后这一跳按整跳走完。很少碰到，先不管。
- 重生点是控制器第一次见到角色时的位置，TSX 改了角色的声明位置或者重新生成角色都不会更新它（R 重新开始也回到这里）。

## 验收记录（2026-11-04，Mac）

- **单元测试**：`nge-physics2d` 新增 4 个（`contacts` 报对方和法线、sensor 不算接触；`LockRotation` 让箱子在台阶边不倒、去掉后会倒、加锁时清掉已有的转速）；`nge-scene` 新增 1 个（`fixedRotation` 加上 / 去掉）；`examples/platformer` 9 个，后来移动平台加 2 个、手柄加 1 个、音效和重来加 4 个，敌人加 3 个，现在 19 个（走和停、只能从地上跳且松键截短、多个跳跃键全松开才截短、跳跃缓冲、土狼时间、贴墙不能跳、掉坑重生发 `respawn`、穿过金币发 `collide`、暂停时不响应按键）。截短的两个用例用变异实验确认过：去掉截断或去掉「全松开」条件测试会挂。
- **敌人的测试**：从上面落到敌人身上发 `stomp`、弹起来、出声，TSX 还没去掉刚体时再落上去不重复发，R 以后又能踩；按着跳弹得高；从侧面走过去撞上发 `respawn`、回到起点；App.tsx 的敌人 id 前缀和 Rust 对得上；`nge-scene` 1 个（去掉、加回刚体时补间接着走）。变异实验：去掉「踩过的不再算」、R 不清踩过的、踩到时不看跳跃键，各有测试会挂。去掉了测不到也碰不到的「敌人不算地」「踩到优先」两条规则，补了上面的测试，掉坑时不清踩过的敌人，把太挤的第二只挪了地方。
- **音效和重来的测试**：起跳和掉坑各出一个声音、按 R 回起点发 `restart` 且按住不重复、掉坑次数从 0 重新数、和起跳同一帧时只重来且不出声、暂停时不重来、五个 wav 都打包了且 App.tsx 引用的 uri 对得上。变异实验：去掉掉坑音效、去掉重来时清控制状态、去掉重来分支的提前返回，各有一个测试会挂。补了上面后三个测试、手柄菜单键也能重来、掉坑时一并清跳跃缓冲、音尾淡出、脚本不依赖当前目录、文档。音量和听感还没手测。
- **修过的问题**：修了解锁旋转的测试太弱、第二个坑上方的平台会撞头、控制没挡住暂停和坏帧时间、起跳后一帧的预测接触点导致连跳、截短的测试上界和整跳贴在一起测不出截断。
- **TS**：`nsh check` 通过 `examples/scene`、`examples/physics`、`examples/scene3d`、`examples/platformer`。
- **iOS**：`cargo check --workspace --target aarch64-apple-ios` 通过。
- **实跑**：`platformer`（release + `nsh dev --server-only`）在 Mac 上启动，dev server 显示 macOS host 已连接、热重载正常；手测时发现两处卡顿，都修了，复测不卡：
