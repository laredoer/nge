# 本地化：多语言文案、复数、跟着系统语言

> 前置：TSX 绑定（[m3-tsx.md](m3-tsx.md)）。

## 目标

游戏里的文字（HUD、关卡名、气泡、浮字）现在都直接写死成中文，换个语言要把代码里的字符串一个个改掉；数量相关的句子（「1 coin / 3 coins」）没法按语言变；也不知道玩家的系统是什么语言。

**验收标准**：
- 每种语言一份文案表，按键取文案，文案里可以带 `{参数}`。
- 带数量的文案按语言的复数规则选（英语分单复数、中文不分、俄语分好几种）。
- 默认跟着系统语言（nsh 的 `locale`），找不到时退到同语言的其他地区、再退到默认语言；游戏也能自己指定语言。
- 换了语言，用到文案的界面自己刷新。
- 能查出哪种语言还缺哪些文案（写进测试）。
- 平台跳跃：中文和英文两套文案，HUD、关卡名气泡、浮字都换；按 L 切语言，记在设备上。

## 做法

### `ts/i18n.ts`（从 `ts/nge.tsx` 导出）

```ts
const ZH = { coins: "金币 {got} / {all}", fell: { other: "失手 {count} 次" } };
const EN: Messages<typeof ZH> = { coins: "Coins {got} / {all}", fell: { one: "{count} fall", other: "{count} falls" } };
const lang = i18n({ messages: { zh: ZH, en: EN }, fallback: "zh" });
lang.t("fell", { count: 2 }); // "2 falls"
```

- 文案是字符串，或者按复数类别写的对象 `{ zero?, one?, two?, few?, many?, other }`。复数文案按参数 `count` 选；没写的类别用 `other`；没给 `count` 时用 `other`。`count` 按原值选类别、显示时按语言格式化（最多三位小数），所以最好是整数。
- 默认语言以外的文案表要标上 `Messages<typeof 默认表>`：不标时拼错的键会被当成新键，类型查不出来。
- `{名字}` 换成参数（名字只能是字母、数字、下划线；只读游戏传的参数，不读到 `constructor` 这些原型上的东西）：数字按当前语言格式化（`Intl.NumberFormat`，没有时用 `String`），字符串原样；没给的参数原样留着 `{名字}`，方便一眼看出来。`{{` 和 `}}` 是字面的花括号。
- 语言选择 `resolveLocale(tag, available, fallback)`：
  - 标签不分大小写，`_` 当 `-`。
  - 中文没写文字时按地区补上：`zh-TW`、`zh-HK`、`zh-MO` 当 `zh-Hant-…`，别的地区当 `zh-Hans-…`。
  - 先找完全一样的，再一段一段往前截（`zh-Hans-CN` → `zh-Hans` → `zh`），再找同一种语言的（`en-GB` 找到 `en-US`；文字一样的优先，`zh-Hant-HK` 找到 `zh-TW` 而不是 `zh-CN`），都没有用 `fallback`。
- 取文案：当前语言没有这个键就用 `fallback` 语言的，复数也按 `fallback` 语言的规则选（不然俄语的 21 会选到英语的单数）；都没有返回键名，并且同一个键只警告一次。
- `lang.locale()`：现在用的语言（文案表里的键），读的是 signal（会被跟踪），`t` 读它，所以换语言后界面自己刷新。
- `lang.setLocale(tag)`：游戏指定语言（也按上面的规则找）；`setLocale(null)` 回到跟系统，不是字符串的（存档读回来的坏值）也当 `null`。
- `lang.locales`：有哪些语言。
- `missing(messages, fallback)`：每种语言比默认语言缺哪些键（复数文案也要有 `other`），给测试用。
- 复数规则自己带一张表（nsh 的运行时没有 `Intl.PluralRules`）：
  - 不分：`zh`、`ja`、`ko`、`th`、`vi`、`id`、`ms`。
  - `one` / `other`（`n` 是 1）：`en`、`de`、`nl`、`sv`、`no`、`nb`、`fi`、`el`、`hu`、`tr`，以及表里没有的语言。
  - `one` / `many` / `other`（`n` 是 1；整百万是 `many`）：`es`、`it`、`pt-PT` 和巴西以外的葡语。
  - `one` 是 0 到 2 之间（不含 2），整百万是 `many`：`fr`、`pt` 和 `pt-BR`。
  - 丹麦语 `da`：1，以及整数部分是 0 或 1 的小数是 `one`。
  - `one` / `few` / `many` / `other`：`ru`、`uk`（个位 1 不是 11 → `one`；个位 2 到 4、不是 12 到 14 → `few`；其他整数 `many`；小数 `other`）；`pl`（只有 1 是 `one`，其余同上）。
  - `zero` / `one` / `two` / `few` / `many` / `other`：`ar`。

### 示例（平台跳跃）

- `strings.ts`：中文和英文两份文案（HUD 的每一段、关卡名、浮字「踩！」、存档位、操作说明），英文按复数写「falls」「coins」。
- 语言默认跟系统；按 L 在中文和英文之间切，用 `saved("lang")` 记在设备上。
- 关卡名气泡、HUD、浮字都用 `t`。气泡存的是关卡号，画的时候才取文案，换语言时跟着换（重新打一遍）。
- `saved("lang")` 读回来的不是字符串时当成跟系统。

## 不做

- 从右往左的排版（阿拉伯语、希伯来语）：文字渲染器不做双向排版。
- 按语言换字体：现在不指定字体时用系统字体回退，中日韩在 iOS 和 Mac 上都有。
- 性别、序数、日期格式。
- 文案文件热更新、从服务器下载语言包。
- Rust 侧的文案：Rust 里出现的文字（调试面板）不翻译。
- 别的复数规则：表里没有的语言按英语，`hi`、`bn`、`fa`、`cs`、`sk`、`he`、`ro`、`lt`、`lv`、`hr`、`sr` 这些实际的规则不一样，用到时再加。
- 手机上切语言：平台跳跃只有 L 键能切，手机上跟系统；切过以后不能回到「跟系统」。

## 修过的问题

- 当前语言缺的文案退到默认语言时，复数还按当前语言选，俄语的 21 显示成英语的单数；改成按文案所在的语言选。
- `zh-TW`、`zh-HK` 落到简体上；没写文字的中文按地区补上繁简。
- 存档里的语言不是字符串时，切语言抛异常；当成跟系统。
- 文案里写 `{constructor}` 又没传参数时，插进去的是函数源码；只读游戏传的参数。
- 关卡名气泡换语言后还是旧语言；存关卡号，画的时候取文案。
- 法西意葡的整百万、丹麦语的小数、巴西以外的葡语选错复数类别。
- 每替换一个数字就新建一个 `Intl.NumberFormat`；按语言缓存。

## 验收

- `i18n.test.tsx`（平台跳跃里）：
  - 参数替换、数字格式化、缺参数原样留着、花括号转义。
  - 复数：英语、中文、法语、俄语、波兰语、阿拉伯语的几个关键数字；没写的类别退到 `other`；没给 `count` 用 `other`。
  - 语言选择：完全一样、截短、同语言别的地区、大小写和下划线、找不到用默认。
  - 缺文案退到默认语言、都没有返回键名只警告一次；`setLocale` 和 `setLocale(null)`；换语言后 `t` 跟着变。
  - `missing` 找出缺的键和缺 `other` 的复数文案。
- 平台跳跃：英文文案一条不缺；每个文案的参数在两种语言里一样；中文关卡名和关卡表的名字一样。
- 变异检查：下划线和大小写、截短、同语言别的地区、巴西和葡萄牙葡语、法语的 0、俄语的小数和 11、12 到 14、波兰语的 1 和 21、阿拉伯语每一类、负数取绝对值、不分复数的语言、数字格式化、花括号转义、缺参数留着、按当前语言选复数、没写的类别用 `other`、退到默认语言、只警告一次、回到系统语言、缺 `other`、不缺的不列、默认语言要在表里；示例的英文单数、记住语言，改掉都有测试报错。
  - 阿拉伯语 `many` 的下界写成 10 还是 11 一样：10 先被 `few` 接走。
- 还没手测：英文界面在画面上的样子。
