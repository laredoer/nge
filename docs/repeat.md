# 背景重复

> 前置：视差背景（[parallax.md](parallax.md)）、2D 相机（[camera.md](camera.md)）。

## 目标

视差背景按相机在原点时摆，相机走远了背景就到头了。平台跳跃的远山是 12 个方块排出来的，关卡再长一点就得多摆几个，还得算视差层要铺多宽。远山、云、天空、无限长的地面，应该一个节点就能铺满。

**验收标准**：
- 精灵写 `repeat: "x"`，沿世界的 x 轴一个挨一个铺满视野，相机走到哪都有；`"y"` 竖着铺，`"xy"` 铺满整个平面。
- 和视差一起用：铺的是画的位置（加了视差偏移以后）。
- 只画和视野相交的那几份，不管关卡多长。
- 平台跳跃的远山换成一张能无缝接上的山丘贴图，横向重复。

## 做法

### TSX

```ts
{ id: "hills", texture: "asset:/@platformer/hills.png", y: 88, w: 384, h: 240, z: -10, parallax: [0.2, 1], repeat: "x" }
```

- **步长**：精灵画出来的宽、高（含 `scale`），挨着铺，第 k 份在 `位置 + k × 步长`。
- **旋转**：步长不管旋转，沿世界的轴铺。转了的精灵铺出来会重叠或者有缝，一般别转。
- **点击和碰撞**：只有原来那一份。`body`、`tap` 和 `repeat` 一起写时 warn。
- **值**：`"x"`、`"y"`、`"xy"`，写别的这个精灵解析失败、跳过（和别的字段一样，只记 warn（见 [m3-tsx.md](m3-tsx.md) 的「场景里写错一项」））。

### 引擎

- **组件**：`nge-render2d` 加 `Repeat { x, y }`，场景同步按 `repeat` 加上或去掉。
- **视野**：`Camera2d::visible(size)`，视口四个角换到世界坐标后取外接框。相机转了时比视野大，多画几份不要紧。
- **铺几份**：`repeat::copies` 按画的位置、步长和一份的外接框（含旋转）算出和视野相交的 k，每个轴分开算，在 f64 里算（坐标很大时也对得齐）。不重复的轴只有原来那一份，不在视野里时一份都不画。
- **上限**：一个精灵一帧最多 4096 份。步长不是正数（大小是 0、NaN）或者超过上限（比如相机缩得很小）时只画原来那一份，每个精灵 warn 一次，写明份数、步长和视野大小。
- **贴图还在加载**：没写 `w` / `h` 的精灵，大小要等贴图加载完才知道（之前按 1 × 1），这时先不铺，只画一份。
- **渲染**：精灵渲染器提取精灵时，有 `Repeat` 的按 `copies` 推多个实例，其余照旧。合批不变：同一张图的几份挨着，是一次 draw。

## 不做

- 份与份之间留空隙、错开：用透明边的贴图。
- 按 UV 平铺一张大四边形（一次画完、不分份）：份数不多，实例够用。
- 瓦片地图的重复：瓦片地图有碰撞体，重复出来的没法碰。

## 验收

- `nge-render2d`：
  - `copies`：沿 x 铺满视野、竖着只有一份；原来那份远在视野外照样铺进来、按原来的位置对齐；`"xy"` 铺成网格；步长是 0、负数、NaN、太小时只画一份；旋转后外接框变大，露出来的也算。
  - `Camera2d::visible`：缩放、旋转后的外接框。
  - 离屏渲染：相机挪到 x = 5000，16 × 8 的条带横着铺满画面、竖着只有一行。变异检查：渲染器不按 `Repeat` 铺时失败。
- `nge-scene`：`repeat` 的三种值加上组件，去掉时组件也去掉。
  - 和视差一起用：竖直视差 0 的条带钉在屏幕中间那一行横着铺满。变异检查：按声明的位置铺时失败。
  - `copies` 另外三个：份数报回去；不重复的轴出了视野时不画；中心在 3e8 时照样按步长铺满。
  - `rotated_half`：不转、镜像后转 90°、转 45°。
- `nge-scene`：写错的值（`"z"`）只丢这个精灵，别的照常。
- 平台跳跃：远山是 `tools/make_hills.py` 生成的 256 × 160 山丘剪影（几条正弦叠起来，周期都是宽度的整数分之一，左右两头一样高），白色，由精灵的 `color` 染色。放大 1.5 倍，最低处也高出地面。
- **修过的问题**：贴图还没加载完时按 1 × 1 铺，误报份数太多；份数太多的警告全局只报一次，之后别的精灵配错了没有提示；坐标很大时 f32 算错份数；不重复的轴出了视野还推一整排；视野大小 0 时和 `view_proj` 不一致；远山太矮，有几段被地面挡住。
- 还没手测：Mac 上往右跑到底，远山一直有、接缝看不出来。相邻两份共用的边分别算，偶尔可能差一点露出一列缝，手测时注意看；真有的话改成按 UV 平铺。
