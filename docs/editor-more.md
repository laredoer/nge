# 编辑器补齐：多层瓦片、旋转和层级、第三轮玩法的编辑、交互、试玩热重载

> 前置：关卡编辑器（[editor.md](editor.md)）、2D 玩法补齐（[gameplay2d.md](gameplay2d.md)）、预制体（[scene-flow.md](scene-flow.md)）、大场景性能（[big-scene-perf.md](big-scene-perf.md)）、触屏输入（[touch-input.md](touch-input.md)）。

## 目标

[editor.md](editor.md) 的「不做」里留了一串：刷子只画第一层瓦片、不能旋转实体、场景树是平的、没有滚轮缩放和悬停高亮、试玩时不能边玩边改。第三轮又加了单向平台、斜坡、动画瓦片、行为树、预制体，编辑器只能刷这些瓦片，改不了它们的规则，也摆不了走地怪的路线和预制体。这一项把这些补上。

**验收标准**：

- 关卡文件升到第 2 版：瓦片层多了名字、显隐、锁定、视差；实体多了旋转、z、父节点、路线点、预制体覆盖。第 1 版的文件照样读（迁移有测试），平台跳跃的「石阶」存成第 2 版、照样加载。
- 多个瓦片层：层面板能加、删、上移下移、显隐、锁定、改名、设视差和 z；刷子、矩形、油漆桶画在当前层；锁定的层画不上，隐藏的层编辑器里不画。
- 瓦片的矩形填充和油漆桶（四连通）是纯函数，有测试。
- 当前层上某一种瓦片的规则能改：实心 / 单向 / 斜坡（两头高）/ 不挡，动画帧和 fps，摩擦、弹性。
- 实体：装饰（`deco`）和模型能旋转，装饰能单独设 z；分组（`group`）和父子层级：场景树按层级缩进、能折叠，按住一行拖到另一行上改父节点（拖到空白处回到最外层），属性面板也能填父节点；移动父节点时子孙跟着动，删父节点连子孙一起删，复制带着子孙。
- 走地怪：速度、跳跃、视野、两头停多久能改；路线点在画布上画出来、按住能拖，属性面板加点、删点；游戏里按路线来回巡逻。
- 物件库能放预制体实例（平台跳跃的「树丛」「树」），属性面板加、删按子节点的覆盖；游戏里照样展开。
- 交互：悬停高亮（选择工具下指针下面那个实体描一圈）；拖动、框选时指针到画布边上自动滚动；缩放以指针为中心（触控板捏合、Control + 滚轮、⌘+ / ⌘-）。
- 试玩热重载：试玩时左右两边的面板还在，改了关卡（属性、删除、撤销、保存……）正在跑的这一关就地更新，不重开；瓦片的改动用 `setTiles` 发，不重建地图。
- 纯逻辑（格式迁移、层操作、填充、层级、覆盖、路线点、悬停、自动滚动、热重载的瓦片差异）都有测试；变异验证至少 15 个。

## 做法

### 关卡文件第 2 版（`ts/level.ts`）

```json
{
  "format": "nge-level",
  "version": 2,
  "tiles": [
    { "id": "level", "name": "地面", …, "data": [ … ] },
    { "id": "far", "name": "远处", "parallax": [0.6, 1], "z": -70, "hidden": false, "locked": true, …, "data": [ … ] }
  ],
  "entities": [
    { "id": "g1", "type": "group", "name": "第一组金币", "x": 300, "y": 80 },
    { "id": "e7", "type": "coin", "x": 288, "y": 60, "parent": "g1" },
    { "id": "e9", "type": "deco", "x": 500, "y": 40, "rotation": 30, "z": -5, "props": { "color": "#556677" } },
    { "id": "e10", "type": "walker", "x": 1200, "y": 12, "points": [[1300, 12], [1400, 76]] },
    { "id": "e11", "type": "prefab", "x": 200, "y": 0, "props": { "prefab": "grove" }, "set": { "b/crown": { "y": 110 } } }
  ]
}
```

- 瓦片层新增（都可选）：`name`（层面板上显示，不超过 64 个字）、`hidden` / `locked`（布尔，只给编辑器用）、`parallax`（`[x, y]`，0 … 4）。`toTilemap` 去掉 `name`、`hidden`、`locked`，带上 `parallax`。
- 实体新增（都可选）：`rotation`（度，±3600 以内）、`z`（坐标范围）、`parent`（另一个实体的 id）、`points`（`[[x, y], …]`，最多 64 个）、`set`（`{ 子节点路径: { 字段: 值 } }`，路径是 `a/crown` 这样的 id 用 `/` 连起来、最多 8 段，字段名和属性名一样的规则，值和属性值一样只能是有限数、布尔、字符串，最多 32 个子节点）。
- `parent` 要指向关卡里有的实体，不能是自己，不能绕成圈（`a` 的父是 `b`、`b` 的父是 `a`）。
- 坐标都是世界坐标，父节点只是层级：游戏读关卡时不用管父子（位置已经是算好的），编辑器移动父节点时把子孙一起挪。父节点转了不带着子节点转（见「不做」）。
- **迁移**：`LEVEL_MIGRATIONS[n]` 把第 `n` 版的原始对象变成第 `n + 1` 版，`parseLevel` 从文件的版本一步步迁到现在的版本再校验。1 → 2：第 1 版的读法不认识的字段（上面这些）一律丢掉，免得一个第 1 版的文件里碰巧有个 `parent` 字段，升级以后意思变了；然后把 `version` 改成 2。迁移不改传进来的对象。读进来的关卡 `version` 都是现在的版本，存的时候就是第 2 版。

### 平台跳跃的新类型（`examples/platformer/catalog.ts`）

| 类型 | 名字 | 属性 | 游戏里 |
|---|---|---|---|
| `group` | 分组 | | 什么都不生成，只在编辑器里当文件夹 |
| `deco` | 装饰 | `color`、`w` × `h` 能改 | 一个没有刚体的色块（`decos`），按 `rotation`、`z` 画 |
| `prefab` | 预制体 | `prefab`（`grove` / `tree`） | 预制体实例（`instances`），带 `set` 覆盖 |
| `walker` | 走地怪 | 原来的 `patrol`，加 `speed`（40–400）、`jump`（200–1200）、`sight`（1–30 格）、`rest`（每个点停几秒，0–5） | 有 `points` 时按「出生点 → 路线点 → … → 原路回来」来回走，`patrol` 不算 |

- 类型表加 `rotatable`（能转：装饰、模型）和 `layered`（能单独设 z：装饰），属性面板只给这些类型显示旋转、z。模型的旋转转成 `rotation: [0, 0, 度]`。
- 包围盒按旋转后的四个角取外接矩形（`boundsOf`），转过的东西也点得中、框得到。
- 游戏里的 id 按编辑器里实体的 id 生成（`coin:e5`、`enemy-patrol:e7`、`enemy-walker:e9`、`lift:e2`……）：删掉、重排前面的东西，后面的 id 不变，拿过的金币、踩过的敌人还记在对的上面。实体 id 里没有 `:`，不同类型的不会撞；敌人照样以 `enemy-` 开头。状态栏的「得到」只数关卡里还有的金币。代码写的关卡（第一关、第三关）的 id 不变。

### 编辑核心（`examples/editor/`）

- `layers.ts`：层的命令（加一层：和当前层一样大、一样的图集和规则、全空，id 是 `layer<n>`；删一层：不能删最后一层；挪一层；改层的字段，撤回时还原）；当前层上某一帧的规则（`frameRule` 读、`withFrameRule` 写，返回新的层：实心、单向、斜坡互斥，换种类时从别的列表里去掉；动画和材质各自的列表，没有就去掉那一项）；视差层的拾取（`layerPoint`：世界坐标减去「相机 ×（1 − 视差）」才是这一层上的位置）。
- `fill.ts`：`rectCells(a, b)` 两格围成的矩形里的格子；`floodFill(layer, start, frame)` 从起点开始四连通、和起点帧号一样的格子都换成 `frame`（用显式栈，不递归，大地图不爆栈）；起点已经是这一帧时什么都不做。两种都产生 `TileChange`，用原来的 `paintTiles` 命令。
- `hierarchy.ts`：先扫一遍建「父节点 → 孩子」的表，`treeRows`、子孙、`canParent`（往上查祖先）、`setParent` 都是线性的；`childrenOf` / `descendantsOf`；`treeRows(level, collapsed)` 场景树的行（深度、有没有孩子、是不是折起来了），父节点后面跟着它的子孙，顺序是数组里的顺序；`canParent(level, id, parent)`（不能是自己、不能是自己的子孙）；`dropTarget(rows, from, y, rowHeight)` 从第 `from` 行往下拖了 `y` 落到哪一行（落在列表下面是放回最外层，落在原处不算）；`withDescendants(level, ids)` 选中的加上子孙（移动、删除、复制都用它）；`setParent(level, ids, parent)` 一组实体换父节点的命令（不合规的跳过，选中的里面有祖孙时只挪最上面的，撤回还原）。
- `commands.ts`：移动命令（拖、方向键、挪父节点带着的子孙）把路线点一起平移，撤销一起还原；旋转、z、路线点、覆盖走原来的 `updateEntity`。属性面板改 x / y 时自己的路线点也一起平移。
- `clipboard.ts`：复制带着子孙；粘贴时父节点换成一起粘贴的新 id；没一起复制的父节点还是复制时那个就留着，被删了、或者 id 被新东西重用过（删掉最大号以后新放的东西会拿到同一个 id）、换了关卡就放到最外层；路线点跟着偏移。store 记着剪贴板挂在哪些外面的父节点下面，执行命令时新出现的 id 从里面去掉（撤销回来的不算新的）。
- `fields.ts`：属性面板的旋转、z、视差、可空的数、动画帧的输入解析。
- `overrides.ts`：预制体覆盖的输入：`parseOverride(path, field, text)`（路径、字段名的规则同文件格式，值按「数 → 布尔 → 文字」认），`withOverride` / `withoutOverride` 返回新的 `set`。
- `points.ts`：路线点：加一个（在最后一个点右边一格，没有点时在实体右边一格）、删一个、挪一个；`pointAt` 屏幕上点中了哪个路线点（选中的实体的点优先）。
- `view.ts`：`edgeScroll(size, p, margin, speed)`：指针在离边 `margin` 以内时，按离边多近给出这一下往哪边挪多少（越靠边越快，出了画布也按最快算）；`zoomAt` 照旧。
- `tool.ts`：工具加矩形（`rect`，R）和油漆桶（`fill`，G）；刷子、矩形、油漆桶都画当前层，锁定的层不画；按在选中实体的路线点上是拖点（`point`）；拖着实体时子孙一起挪；`hoverOf(ctx, p)` 指针下面的实体。
- `store.ts`：当前层（`layer`）、折叠的分组（`collapsed`）、悬停（`hover`）、最后的指针位置；层面板、瓦片规则、父节点、路线点、覆盖的操作；`autoScroll()`：拖动、框选时按 `edgeScroll` 挪视图，再按最后的指针位置把拖动重算一遍；试玩时的热重载（`relive`，见下）。

### 界面

- 左边下半多一个「层」面板：每层一行（名字、眼睛、锁），点一下设为当前层；下面的按钮加一层、删除、上移、下移。右边属性面板没选中实体时多一节「当前层」：名字、视差 x / y、z，和当前瓦片的规则（种类、坡的两头、动画帧、fps、摩擦、弹性）。
- 场景树按层级缩进，有孩子的行前面是 ▸ / ▾，点它折叠；按住一行拖到另一行上松开是把它（和别的选中的）放进那一行，拖到列表下面的空白处是放回最外层。
- 工具栏加矩形 R、油漆桶 G。
- 画布：指针在画布上（选择工具、没按着）时，下面那个实体描一圈浅色的框；选中的走地怪画路线（连线和点），点能拖。

### 试玩热重载

- 试玩时只换掉中间的画布：工具栏、场景树、物件库、层面板、属性面板都还在，撤销、重做、保存照常。按「回到编辑」或 Esc 回来。
- 编辑器的 `relive()`：试玩中关卡每变一次（执行命令、撤销、重做）就按试玩前的检查查一遍（`trialOf`，只 `fromFile` 一次），换掉 `playing`；不合规（比如删了终点、所有层都有视差没有地面）时留着上一次能玩的，状态栏说为什么没更新，改好了以后状态栏换回「试玩中」。试玩中新建、打开关卡时先停掉试玩。
- 游戏（`game.tsx`）的 `trial` 可以是一个函数（取值时读当前的）。试玩的这一关：
  - 瓦片地图走 `liveTiles`（`examples/platformer/live.ts`）：地图的字段（除了 `data`）和上一次一样时，声明里留着最初的 `data`，变了的格子用 `setTiles` 发；字段变了（改了视差、规则、大小、加了层）就声明新的地图，引擎整张重建（这是引擎原来的规矩：规则变了整张重建）。关卡还没建好（`levelStart` 之前）时也直接声明新的。
  - 角色的起点用开始时的：改了出生点不把正在玩的角色拉回去。
  - 移动平台和巡逻的敌人路线变了时重新发补间。
  - 金币、敌人、灯、装饰、预制体这些照常按声明增量同步（引擎按 id 只改变了的）。
- 不用另开窗口：编辑器和游戏在同一个进程，传给游戏的 `trial` 是读 `playing` 这个 signal 的函数。
- 游戏的 `follow` 是一个 effect，状态和每一步是 `live.ts` 里的纯函数（`startFollow`、`followStep`、`restartFollow`）：关卡开始以后，每次 `trial` 变了就算出要发的 `setTiles`、要声明的地图、变了的平台和敌人的补间；角色起点冻在开始时的值。
  - 补间带着出生点做起点（`liftTweenOf`、`enemyTweenOf` 的 `from`），改了巡逻格数后范围还是以出生点为准；热重载时的补间等场景声明发出去以后（下一个 tick）再发，新加的平台、敌人那时已经在引擎里了。
  - 通关后、血掉光时整关重开（换 `level` 让引擎重建）：先 `restartFollow`，声明换成现在显示的完整地图，重建出来就是改过的样子，之后按重建后的比。

## 不做

- **普通的鼠标滚轮缩放**：nsh 的视图没有滚轮事件（只有 `Scroll` 自己的滚动），游戏视图也收不到。触控板捏合和 Control + 滚轮走 nsh 的 `pinch`，原来就以鼠标位置为中心；⌘+ / ⌘- 改成鼠标在画布上时以鼠标为中心。
- 父节点旋转时子节点跟着转、缩放；子节点的坐标存相对父节点的。
- 引擎里的父子层级：父子只是编辑器里的组织方式，游戏读到的还是一个个独立的节点。
- 预制体里面的节点在编辑器里单独选中、拖动（只能整个实例选中、改覆盖）；覆盖的值只能是数、布尔、文字（不能整个换对象）。
- 斜坡、单向平台的形状在画布上画出来（[gameplay2d.md](gameplay2d.md) 的「不做」）；改图集。
- 多个瓦片层的不同图集（新加的层用当前层的图集）。
- 走地怪路线点之间画导航路径（只画直线）。
- 试玩时在画布上直接拖东西（中间是游戏视图），改要在属性面板里改。
- 热重载不保留走地怪的行为状态：路线、参数变了，声明里的行为树跟着变，引擎换上新树从头跑（黑板清掉，正在追的会先回去巡逻）。
- 热重载时角色不跟着改了的出生点走（起点冻在开始时的）。

## 验收

- 全量检查（按顺序一个一个跑，cargo 都带 `-j 4`）：`cargo test --workspace`、`cargo test -p nge-scene --no-default-features`、平台跳跃 / 长坂坡 / 编辑器逐个 `nsh test <文件>` 和 `nsh check`、iOS 的 `cargo check`（platformer、sanguo）、`tools/check-wasm.sh`、`tools/check-android.sh` 都通过。
- 没改引擎（Rust）：多层、视差、预制体实例、`setTiles` 都是引擎原来就有的。
- 打开编辑器：`cd examples/editor && nsh run`。

## 修过的问题

- 拖到画布边上自动滚动时，拖着的东西不跟着走：拖动的起点记的是屏幕坐标，视图挪了以后起点下面的世界点也跟着挪，算出来的位移还是 0；而且在 `batch` 里读 `view()` 拿到的还是旧值。现在挪视图时起点按屏幕反方向挪同样多，新视图直接传给拖动的重算。
- 场景树拖行用 `onTouchStart` / `onTouchMove` / `onTouchEnd` 放在 `Scroll` 里收不到事件。改用 `pan` 和 `onPanEnd` 的位移。
- 油漆桶第一版用递归、按字符串记走过的格子，1000 × 200 的地图超时。改成整数下标的栈和 `Uint8Array`。
- 新类型（分组、装饰、预制体）没进场景测试的「每种实体都画得出来」，补上。
- 平台跳跃的 Rust 测试按源码文字查 `instances: GROVES`，游戏把关卡里的预制体实例也放进来以后对不上，跟着改。
- 试玩以前整个换成游戏界面，测试期望场景树看不到；现在试玩时面板都在，测试跟着改。
- 试玩中整关重开（通关后、血掉光）时引擎按声明重建地图，声明里还是开始时的格子，之前用 `setTiles` 发的改动全丢了（撤销掉的格子又回来），之后算差异也一直不对。现在重开前把声明换成现在显示的完整地图（`restartFollow`）。
- 游戏里的金币、敌人、平台、装饰、预制体、走地怪按下标编 id：删掉、重排前面的以后，拿过的、踩过的记到了别的上面，状态栏还会出现「得到」比总数多。现在按编辑器里实体的 id 生成，「得到」只数还在的。
- 热重载重发的平台、敌人补间不带起点，从现在的位置开始走：改了巡逻格数以后巡逻范围漂走。现在带着出生点做 `from`。
- 热重载的补间在场景声明之前发：新加的平台、敌人可能还不在引擎里，补间被丢掉。看代码：命令和属性按顺序进同一条消息通道，引擎同一帧里先同步场景（PreUpdate）再起补间（Update），但命令排在属性前面，引擎刚好在两条之间取消息时补间会找不到精灵。现在等场景声明发出去以后（下一个 tick）再发，中间换了关的不发。没在真机上复现过。
- 挪走地怪或它的父节点（拖、方向键、改 x / y）时路线点不动，粘贴时却跟着偏移。现在移动命令把路线点一起平移，撤销一起还原。
- 层级的函数每次都扫全部实体，场景树是平方的：5000 个实体时超过 2 秒的时限被打断，2000 个里选 300 个换父节点也是。现在先建一次「父节点 → 孩子」的表，往上查祖先判断能不能放，都是线性的。属性面板改父节点的 x / y 时找子孙也是每个实体扫一遍，一起改了。
- 粘贴时只看父节点的 id 还在不在，id 会被重用（删掉最大号以后新放的东西拿到同一个 id），粘贴出来的挂到了不相干的东西下面。现在记着剪贴板挂在哪些外面的父节点下面，复制以后这个 id 被新东西用了、换了关卡就放到最外层。
- 试玩中能新建、打开关卡，正在玩的被换成另一关，起点还是旧关的。现在换关卡时先停掉试玩。
- 拖几行放进分组时有一个不合规整组都不放，和「不合规的跳过」不一样。现在不合规的跳过，状态栏说跳过了几个。
- 热重载不合规以后又改好了，状态栏还停在「试玩里先不更新」；检查和热重载各转了一次关卡。现在合成一次，改好以后状态栏换回来。
- 走地怪的路线到最后一个点后直接走回出生点（绕圈），和「来回走」不一样。现在原路回来。
- 覆盖的子节点路径 `__proto__` 能通过校验，写进对象时被吞掉。现在路径里不能有这一段。
- 所有层都设了视差（没有挡人的地面）也能试玩。现在说「没有挡人的瓦片层」。
