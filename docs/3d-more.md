# 3D 补齐：阴影、骨骼动画、模型和精灵按深度混排

> 前置：基础 3D（[m4-3d.md](m4-3d.md)）、2.5D 相机（[camera25d.md](camera25d.md)）、2D 特效（[effects2d.md](effects2d.md)）。

## 目标

3D 模型没有影子，看着是浮在空中的；glTF 里的骨骼动画读不进来，旗子、角色只能整块转；精灵和模型只能分两层，z < 0 的精灵整个画在模型下面、其余的整个画在上面，角色没法从模型后面走过去。

**验收标准**：
- 方向光写 `shadows: true` 投影子：模型挡住的地方变暗，挡不住的照常亮。
- glTF 的蒙皮（skins）和动画（animations）读进来：平移、旋转、缩放三种通道，STEP、LINEAR、CUBICSPLINE 三种插值；模型节点写 `animation: { clip, speed, loop }` 播。
- 3D 相机写 `interleave: true` 时精灵按 z 和模型比深度：模型后面的精灵被挡住，前面的露出来。
- 平台跳跃：终点旗杆顶上一面挥动的 3D 旗子，角色跳过终点时从布后面经过；箱子顶上的小箱子在大箱子顶面投下影子。

## 做法

### 方向光阴影（`nge-render3d` 的 `shadow.rs`）

- `DirectionalLight::shadows`：第一盏开着的方向光投影子，其余的忽略（方向为 0 的不算）。「第一盏」按 ECS 查询的顺序，增删实体后可能换，所以只开一盏。
- 资源 `Shadows { size }`：阴影图边长，默认 2048，限制在 [64, 4096]。
- 每帧先从光那边正交地画一张深度图（`Depth32Float`），只画深度、两面都画（薄片也挡光）。光的矩阵按所有 draw 的世界包围盒拟合：在光的视图里取包围盒，四周留 2%。物体铺得很开时一个像素管的范围大，影子边缘会粗。
- 主 pass 里 3×3 PCF 采样（比较采样器）；阴影图外面的算照到。算坏了（不是有限数）的包围盒不参与拟合。斜面防阴影痘：画深度时按斜率加偏移，采样时沿法线往外推 1.5 个阴影图像素。
- 网格上传时算好本地包围盒；蒙皮的网格用每个关节各自变换后的包围盒合起来（蒙皮后的顶点一定落在里面）。

### 骨骼动画（`animation.rs`）

- 数据：
  - `Model` 多了 `skeleton`（节点树，父在前；蒙皮的关节和逆绑定矩阵）和 `animations`（每段有名字、时长、若干通道）。
  - `Part` 多了 `node`（挂在哪个节点上）和 `skin`（用哪套蒙皮）。
  - `Mesh` 多了 `skin`（每个顶点最多 4 个关节和权重）。
  - `Assets3d::add_model` 校验：父节点在前、关节和通道引用的节点存在、关键帧数对得上、时间不递减、网格的关节编号在蒙皮里。
- glTF 读取：
  - 默认场景的节点树按先父后子展开；不在默认场景里的节点上的动画通道跳过。
  - 蒙皮的关节不在默认场景里、逆绑定矩阵数不对时，这套蒙皮不用，按不蒙皮画（warn）。
  - 权重归一化；没名字的动画按编号叫（"0"、"1"…）；变形权重（morph target）通道跳过。
  - 读不出数据、关键帧数对不上、时间不对的通道只丢这一条（warn），模型照常加载。
  - 零四元数、不是有限数的四元数当作不转。
- 播放：组件 `Animator { clip, speed, looping, time }`（自动带上 `Pose`）。`PostUpdate` 里按 `Time` 的帧间隔推进：循环时绕回开头，不循环时停在最后一帧，速度可以是负数（倒着播）。按时间采样每个通道，算出每个节点相对模型原点的矩阵写进 `Pose`。名字找不到时停在不播动画的姿势，warn 一次。渲染器只在还有 `Animator` 时用 `Pose`，单独去掉 `Animator` 就回到不播动画的姿势。
- 渲染：
  - 不蒙皮的部件挂在节点上时，按 `Pose` 里这个节点的矩阵画；没有 `Pose` 时按 `local`。
  - 蒙皮的部件在 GPU 上变形：关节矩阵（节点矩阵 × 逆绑定矩阵）每帧写进一个 storage buffer，和 draw 的 uniform 在同一个 bind group，draw 里记从第几个开始。蒙皮的网格多一个顶点缓冲（关节、权重），主 pass 和阴影 pass 各多一套蒙皮管线。没在播动画的蒙皮模型按不播动画的姿势画。

### 模型和精灵按深度混排（`nge-ecs`、`nge-render2d`）

- 资源 `Interleave(bool)`，默认关。关着时和以前一样：z < 0 的精灵画在模型下面，其余画在上面。
- 开着时：
  - 3D 的深度缓冲（改成 `Depth24PlusStencil8`）留下来，连同 3D 相机的矩阵放进 `RenderFrame`。
  - 精灵全部画在模型之后，用同一张深度缓冲比深度（`LessEqual`，不写深度），精灵的 z 当作 3D 世界的 z。精灵是半透明的，彼此之间还是按 z 排序画。
  - 遮罩照常能用（共用这张缓冲的模板，画精灵前清零）。

### 场景和 TSX

- `lights[].shadows`。
- `camera3d.interleave`；不声明 `camera3d` 时关掉。
- `models[].animation: { clip, speed?, loop? }`，speed 默认 1，loop 默认 true。只改 speed、loop 时接着播；换了动画名或模型从头播；去掉 `animation` 时停下，回到不播动画的姿势。

### 示例（平台跳跃）

- `tools/gen_glb.py` 生成 `flag.glb`：一块宽 1、高 0.6 的布，4 节骨头连成一串，动画 `wave` 让每节错开相位绕 y 摆、绕 z 微微下垂。
- 旗子挂在旗杆右上角，放大 40 倍。布摆起来前后各约 20，放在 z = 30，整块都在角色（z = 5）前面。
- `camera3d.interleave` 打开；背景的 z 挪到 -50 以下，比箱子（前后各 20 多）更靠后，才不会盖住箱子。
- 太阳开 `shadows`：箱子顶上的小箱子在大箱子顶面投下影子。2D 精灵不接受影子。

## 不做

- 点光源、聚光灯的阴影；级联阴影（CSM）；软阴影（PCSS）。
- 精灵接受或投下影子。
- 动画混合、过渡、动画事件；变形（morph target）；多套 UV 的蒙皮。
- 每个模型单独的深度排序（半透明模型）。
- 不支持 storage buffer 的设备（WebGL2、部分旧 Android）：关节矩阵放在 storage buffer 里，所有 3D 管线都绑着它，在这类设备上 3D 画不出来。做 Android / Web 时再换成有上限的 uniform 数组，或者给不蒙皮的单独一套布局。

## 验收

- `nge-render3d` 单元测试：
  - 线性、STEP 插值和超出范围时取两头；旋转按 slerp；三次样条过关键帧、用上切线。
  - 两节的棍子：不播动画时关节矩阵是单位阵，关节转 90° 后绑定的点到了对的位置。
  - 节点树、蒙皮、动画、网格关节编号的校验。
  - `Animator`：推进、循环、两倍速、不循环停在最后、倒着播；名字找不到时停在不播动画的姿势，改对了接着播。
  - glTF：节点按父在前展开、关节换成展开后的下标、逆绑定矩阵、权重归一化、动画的名字（没名字的按编号）、通道和插值；关节不在场景里时去掉蒙皮、跳过通道；坏通道只丢这一条。
  - 零四元数、NaN 四元数当作不转。
  - 阴影图拟合框住所有包围盒，高的点深度小；没有物体、方向是 0 时不拟合。第一盏开着的方向光投影子。
- `nge-render3d` 离屏渲染测试（读回像素）：
  - 开着阴影时方块后面的地面变暗（只剩环境光），照到的地方和方块顶面亮；关着时地面一样亮。
  - 蒙皮的竖条：不播动画（只剩一个弯着的 `Pose`）时竖着，关节转 90° 后上半截倒向左边（同时开着阴影，蒙皮的阴影管线也跑一遍）。
  - 挂在节点上的方块跟着节点动画移走。
  - 混排开着：z ≥ 0 但在模型后面的精灵被挡，z < 0 但在模型前面的露出来，z 很大的不被裁掉；关着时和以前一样。
- `nge-scene`：`shadows`、`interleave` 跟着场景，默认都关；`animation` 默认原速循环，只改速度和循环时接着播，换动画、换模型从头播，去掉时停下。
- 平台跳跃：Rust 测试加载 `flag.glb`，播 `wave` 时布的末端前后摆；TS 测试：旗子挂在旗杆右上角，在角色前面，播 `wave`。
- 变异检查：改掉插值的区间查找、旋转的 slerp、三次样条两头的切线缩放、父子矩阵的乘法顺序、逆绑定矩阵、循环和不循环的时间处理（含倒着播）、速度、节点树和时间顺序的校验、网格关节编号的校验、权重归一化、glTF 节点下标的换算、坏通道的丢弃、零四元数、节点动画、蒙皮管线和关节起点、着色器里的蒙皮、阴影采样、阴影 pass、投影子的光的选择、拟合的留边、混排时的分层、精灵深度的 z 和截断、深度留给精灵、场景里动画的接着播 / 从头播 / 去掉、`interleave` 和 `shadows` 的同步，都有测试报错。
- 还没手测：旗子挥动和箱子上的影子在 Mac、iPhone 上的样子，角色从旗子后面经过，阴影 pass 和蒙皮对帧率的影响（尤其 iPhone），iPhone 上 `Depth32Float` 配线性过滤的比较采样器能不能用。

## 修过的问题

- Rust 里单独去掉 `Animator` 时 `Pose` 还在，模型冻在最后一帧；现在渲染器只在有 `Animator` 时用 `Pose`。
- glTF 里一条通道的关键帧数或时间不对，整个模型加载失败；现在只丢这一条并 warn。读不出数据的通道以前悄悄丢掉，现在也 warn。
- 零四元数归一化得到 NaN，部件整个看不见；现在当作不转。
- 一个算坏了的包围盒会让整个场景的影子消失；现在过滤掉。
- 旗子摆起来布的外侧会摆到角色后面，和「角色从布后面经过」不符；挪到 z = 30。
- 精灵渲染器的文档和遮罩警告还是只讲两层，补上混排时只有一层。
