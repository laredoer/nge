# 管线预热：后台先把 2D 管线编好

> 前置：2D 特效（[effects2d.md](effects2d.md)）。

## 目标

精灵管线和后处理管线都是第一次画到时才编。Metal 驱动编第一条某种管线要 110–390 毫秒，所以第一次闪白、第一次进传送门、第三关第一次开暗角时都会卡一下。

**验收标准**：
- 着色器库到位（或换了一代）后，后台线程把要用的管线先编好，渲染线程拿现成的。
- 后台还没编好时照常当场编，画面和以前一样。
- 换代后，旧一代的结果不会混进新一代。

## 做法

### 后台线程（`nge-render2d` 的 `warm.rs`）

- `Warm<T>`：每开一批起一个后台线程，结果按批次编号发回来。
  - 渲染线程每帧收一次，不等。
  - 开了新的一批后，旧批次的结果直接丢掉；旧线程下一次交结果时得知自己过时了，就不再编了。
  - 后台线程结束（包括编管线时 panic）都会报收工。开不了线程时不预热，只 warn。
- wgpu 的 `Device`、`PipelineLayout`、`ShaderModule` 都可以克隆、跨线程用，后台线程拿克隆的来编。

### 精灵管线（`pipes.rs`）

- z < 0 和 z ≥ 0 两层精灵渲染器共用一份 `Pipes`（以前各编各的），只预热一次，编不过的着色器也只报一次。
- `Pipes::sync(gfx, shaders, depth)` 在着色器库换代时（包括第一帧）开一批预热，然后每帧收下编好的。
- 后台先校验、编出库里的每个精灵着色器，再编每个着色器的每种画法（普通、写遮罩、遮罩里、遮罩外），原样画的也算在内。先编这一帧的混排方式，再编另一种；同一种里先编所有着色器的普通画法，遮罩的后编。
  - 编不过的、后处理着色器跳过。用到时照常当场校验，提示一次，按原样画。
- 收下时：
  - 已经当场编过的着色器保留原来的编号，后台编的只补上还没有的管线。
  - 不在库里的名字编号是 0，它们的结果不能占了原样画的位置。

### 后处理管线（`post.rs`）

- 后台编原样搬的那一遍和库里每个后处理着色器。着色器库换代、渲染目标的格式变了都重新预热。
- `nge-ecs` 的 `PostProcess` 多了 `warm(world, gfx)`（默认什么都不做）。`App` 每帧都调它，不开后处理的帧也调，所以第三关开暗角之前管线就编好了。

## 不做

- 3D 管线：本来就是第一帧一次建好的。
- 存到磁盘的管线缓存（`wgpu::PipelineCache`），下次启动直接用。wgpu 30 只在 Vulkan 上实现了 `PIPELINE_CACHE`，Metal 上是空操作；Metal 自己会缓存编好的着色器。等做 Android（Vulkan）时一起做。
- 没有 3D 的游戏也会编混排的那一半管线（排在后面，用不上也不碍事）。
- 换代时原样画的管线也丢掉重编（热重载时可能卡一下，和以前一样）；旧一批手上正在编的那条编完才退出。
- Web：wasm 上 wgpu 的资源不能跨线程，做 Web 时那里不预热。
- 只预热场景里真用到的组合。现在每个着色器的所有画法都编，内置的 4 个精灵着色器 × 8 种加上原样画的，40 条左右，全在后台编。

## 验收

- `warm.rs` 的单元测试：
  - 编好的按顺序交出来。
  - 旧批次的结果丢掉，旧线程被告知过时。
  - 后台线程 panic 了这批也算收工。
- `pipes.rs` 的单元测试（要 GPU）：
  - 预热完，原样画的和内置、游戏写的精灵着色器每种画法、混排与否都有管线。
  - 编不过的和后处理着色器不预热，用到时按原样画。
  - 用的时候拿热好的编号，不再编。
  - 换了一代后旧名字没了，新的都热好；同一代不重新预热；一批没编完就换代，旧的名字不会混进来。
  - 当场编过的保留原编号；编号是 0 的名字不占原样画的位置。
- `post.rs` 的单元测试：
  - 预热完，原样搬的一遍和 4 个后处理着色器都有管线。
  - 精灵着色器不预热，用到时照常跳过。
  - 格式变了以后重新编好。
- 两层精灵渲染器共用一份管线。
- 离屏渲染测试：后处理关着时每帧也调 `warm`。
- 变异检查：两层不共用、去掉换代 / 换格式时的重新预热、同一代不重开、旧批次的过滤、panic 时的收工、当场编过的保留编号、编号 0 的过滤、后处理的 `warm` 调用，都有测试报错。
- 还没手测：平台跳跃里第一次闪白、进传送门、第三关的暗角还卡不卡；后台编管线时渲染线程会不会被驱动的锁拖慢；iPhone 上的效果。

## 修过的问题

- z < 0 和 z ≥ 0 两层精灵渲染器各有一份管线，同一批管线后台编两遍；改成两层共用一份。
- 后台按着色器一个个把四种画法编完，第一帧就用到的普通画法可能排在很后面；改成先编所有着色器的普通画法。
