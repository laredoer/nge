# 2D 特效：自定义着色器、遮罩、2D 光照、后处理

> 前置：2D 渲染（[engine-design.md](engine-design.md)）、调试绘制（[gizmos.md](gizmos.md)）。

## 目标

精灵只能按贴图乘颜色画：做不了受击闪白、描边、水波、圆形的窗口，夜里的关卡只能把颜色一个个调暗，整屏的效果（去色、暗角）也没有地方加。

**验收标准**：
- 着色器库：内置几个常用的，游戏在 TSX 的 `scene.shaders` 里按名字写 WGSL，同名的盖过内置的。
- 精灵写 `shader` 和 `params` 换着色器；写错的、库里没有的报错一次，按原样画，不崩。
- 遮罩：`mask` 的精灵只记下形状（不透明的地方），`masked: "inside" | "outside"` 的只画在里面或外面。
- 2D 光照：`scene.lighting` 有环境光和点光源，灯能跟着精灵走；`unlit` 的精灵、粒子、文字不受光。
- 后处理：`scene.post` 按顺序过一遍整屏的着色器。
- 平台跳跃：金币扫过亮光，被撞回去时闪白，终点上方一个圆形传送门，里面是转着的星空；第三关是夜里，角色带灯，四角压暗。

## 做法

### 着色器库（`nge-render2d::Shaders`）

- 资源 `Shaders`：游戏的着色器（名字 → WGSL）加上内置的，`set` 整份替换，内容一样时不算改；每改一次 `generation` 加一，渲染器按它丢掉编过的管线。
- 内置的（`Shaders::BUILTIN`，各有默认参数）：

  | 名字 | 种类 | 参数 |
  | --- | --- | --- |
  | `flash` | 精灵 | 往 `rgb` 的颜色混，混多少看 `w`（默认白、1） |
  | `outline` | 精灵 | 透明的地方挨着不透明的就描成 `rgb`，`w` 是几个贴图像素宽 |
  | `wave` | 精灵 | 贴图坐标按 sin 横向摆：幅度、频率、速度 |
  | `circle` | 精灵 | 只留内切圆，当圆形遮罩用 |
  | `grayscale` | 后处理 | `x` 是去色程度 |
  | `vignette` | 后处理 | `x` 是程度，`y` 是从中心多远开始暗 |
  | `pixelate` | 后处理 | `x` 是一格多少屏幕像素（取格子中间那个像素的颜色） |

- **精灵着色器**写 `fn effect(e: Effect) -> vec4f`，返回这个像素的颜色（线性、未预乘）。`Effect` 里有：`color`（贴图颜色乘精灵颜色）、`tint`（精灵颜色）、`uv`、`uv_size`（这一格在图集里多大）、`local`（在精灵里的位置，左下 0、右上 1）、`world`（世界坐标）、`params`、`time`（秒）。可以用 `sample(uv)` 在任意位置取贴图，也可以自己定义别的函数。
- **后处理**写 `fn post(p: Post) -> vec4f`。`Post` 里有：`color`（这个像素画出来的颜色）、`uv`（左上 0、右下 1）、`size`（屏幕像素数）、`params`、`time`。`sample(uv)` 在屏幕任意位置取色。
- **校验**：第一次用到时拼成完整的着色器，用 naga 解析、校验，不过时 `log::error`，精灵按原样画、后处理跳过这一遍。错误的行号是完整着色器里的，后面附一句游戏写的那段从第几行开始。
  - 管线布局是固定的：游戏自己声明绑定（`@group` / `@binding`）、`override`、`var<immediate>` 也当编不过（naga 能过，但建管线会失败、整帧都画不出来）。要传数就用 `params`。
  - 精灵着色器当后处理用（或反过来）一样当编不过。
  - 每个名字每一代报一次（后来两层共用一份管线，见 [pipeline-warmup.md](pipeline-warmup.md)）。
  - `Shaders::check_sprite` / `check_post` 给游戏在测试里检查自己写的。
- **默认参数**按名字查内置的：游戏覆盖了内置的名字（比如自己写一个 `flash`），不写 `params` 时拿到的还是内置的默认值。

### 精灵

- 组件 `SpriteShader { name, params }`：用库里的哪个画。
- 实例从 48 字节加到 64 字节：多了 `flags`（bit0 受光）和 `params`。
- **管线**：按（着色器，画法）编号，用到时才编，着色器库换代就丢掉重来。z < 0 和 z ≥ 0 两层的渲染器各编各的。后来加了后台预热、两层共用一份，见 [pipeline-warmup.md](pipeline-warmup.md)。
- **合批**：遮罩先画，其余按 z、纹理排（和以前一样，同 z 同纹理保持原来的先后），相邻同管线同纹理的合成一次 draw。管线号不参与排序：它按着色器第一次用到的先后分，换代会变，拿来排序会让同 z 的精灵上下跳。

### 遮罩（`Masking`）

- 每层 pass 带一个模板缓冲（跟着渲染目标的大小，每层开头清 0）。
- `Write`：颜色不写，不透明（alpha ≥ 0.5，算上精灵着色器的结果）的地方模板记 1。不管 z 多少都先画。
- `Inside`：模板等于 1 才画；`Outside`：不等于 1 才画。
- 同一层的遮罩合在一起，没有「这个精灵只认那个遮罩」。一层里有 `Inside` / `Outside` 的精灵却没有遮罩时 warn 一次（多半是遮罩和它们不在同一层）。

### 2D 光照（`Lighting2d`）

- `enabled` 时，受光的精灵颜色乘上 `ambient + Σ color × intensity × (1 − d / radius)²`（`d` 是这个像素离灯的世界距离），可以超过 1（被照亮）。
- 最多 `MAX_LIGHTS`（32）盏，半径不是正数、位置不是有限数的跳过。
- `Lighting2d::default()` 是关着、环境光白的。
- 受光的是世界里的精灵（包括瓦片地图）；`Unlit` 的、粒子、文字、调试线不受光。3D 模型用自己的灯，不受 2D 光照。

### 后处理（`PostEffects`）

- `nge-ecs` 加了 `PostProcess` 钩子（`App::set_post_process`）：这一帧要后处理时，所有渲染器先画到一张离屏纹理（尺寸、格式和渲染目标一样），再由它画到屏幕上；不要时直接画到屏幕，离屏纹理也放掉。
- `Render2dPlugin` 装上后处理渲染器：`PostEffects` 不空时开，按顺序一遍遍画（两张中间纹理来回用），最后一遍画到屏幕。用不了的跳过；一遍都用不了时原样搬到屏幕上。

### 场景

```ts
scene = {
  shaders: { shimmer: `fn effect(e: Effect) -> vec4f { ... }` },
  sprites: [
    { id: "coin", shader: "shimmer", params: [1.6, 0, 0, 0], unlit: true },
    { id: "hole", w: 64, shader: "circle", mask: true },
    { id: "sky", w: 64, masked: "inside" },
  ],
  lighting: { ambient: "#4a5578", lights: [{ follow: "player", radius: 260, color: "#ffd9a0" }] },
  post: [{ shader: "vignette" }],
}
```

- 精灵的 `params` 不写用着色器的默认值（游戏写的是 0），写了 `params` 没写 `shader` 时 warn。`mask` 和 `masked` 都写时当遮罩，warn。
- `lighting` 写了就开、去掉就关。环境光默认白（不变暗），灯默认白、强度 1。`follow` 的灯每帧（物理、名字牌跟随、相机之后）放在精灵画的位置（有刚体时是插值过的，带视差时是挪过的）加上 `x`、`y`；精灵不存在时 `x`、`y` 当世界坐标。
- `post` 的 `params` 不写用默认值。
- 灯和后处理的字段写错、`masked` 的值写错，只丢那一盏灯、那一项后处理、那个精灵（warn 一次）（见 [m3-tsx.md](m3-tsx.md) 的「场景里写错一项」）。

### 平台跳跃

- `effects.ts`：
  - `shimmer`：一道亮光斜着扫过金币，按世界 x 错开；金币不受光。
  - 被敌人撞回起点、掉坑重生时角色用 `flash` 混白 80%，250 毫秒后去掉。
  - 传送门：终点上方 110 point，一圈紫边（`circle`），圆形遮罩里是 `starfield`（一格格随机的星星，一闪一闪，整片慢慢转）和一颗 45° 转着的半透明方块星，伸出圆外的角被裁掉。没有碰撞体，每关都有。
  - 第三关「云端」是夜里：背景更暗，环境光 `#4a5578`，角色头顶一盏暖色的灯，终点一盏绿的，传送门一盏紫的，加 `vignette` 压暗四角。
- `src/lib.rs` 的测试把 `effects.ts` 里的 WGSL 取出来用 `Shaders::check_sprite` 校验。

## 不做

- 法线贴图、阴影、方向光、聚光灯；灯不受墙挡。
- 遮罩分组（这个精灵只认那个遮罩）、嵌套遮罩、半透明遮罩。
- 后处理的多张输入（bloom 那样先缩小再合起来）、按层后处理（只给背景模糊）。
- 3D 模型的自定义着色器；粒子、文字用自定义着色器。

## 验收

- `nge-render2d` 的单元测试：
  - 内置着色器都编得过；坏的着色器报错里有游戏写的那段从第几行开始；
  - 没写 `effect`、返回类型不对、精灵和后处理用反了、自己声明绑定（包括同一个绑定换个名字）、`override` 都报错，不带绑定的全局变量可以；
  - 游戏的着色器覆盖内置的、内容一样不换代；灯打包进 uniform（跳过坏半径、最多 32 盏）；
  - 实例 64 字节；遮罩不管 z 先画，同 z 同纹理保持原来的顺序，换管线就断开一批。
- `nge-render2d` 的离屏渲染测试（12 个，读回像素）：
  - `flash` 全混成蓝、混一半；游戏写的着色器；编不过的、库里没有的、自己声明绑定的按原样画，旁边的精灵照常画；
  - 着色器库换了代码，下一帧用新的；
  - 遮罩里只画红、遮罩外只画绿（遮罩 z 更大也先记）；`circle` 遮罩是圆的；背景层有自己的遮罩；
  - 环境光 0.25 的白是 sRGB 137，灯心附近 249，`Unlit` 和额外实例（粒子）不受光；光照关着按原样画；
  - 后处理按顺序（跳过不认识的，去色、只留红，再过一遍不改的，三遍来回用两张中间纹理）；不认识的、编不过的、精灵着色器当后处理的都跳过，画面不变；`vignette` 中心不变、角变暗。
- `nge-scene` 新增 4 个：
  - 精灵的 `shader`、默认参数、`mask`、`masked`、`unlit` 加上和去掉，`masked` 写错时只丢那个精灵；
  - `shaders`、`post` 跟着场景，着色器没变不换代；
  - 灯跟着精灵（带视差时按画的位置）、精灵不存在时用 x、y，去掉 `lighting` 就关；灯的字段写错时只丢那一盏灯。
- 平台跳跃：Rust 测试校验 `shimmer`、`starfield` 编得过；TS 测试：传送门在终点正上方，一个圆形遮罩，星空和星星只画在里面；只有第三关是夜里，灯和暗角都在。
- 变异检查：改掉着色器校验、遮罩的模板比较和写入、遮罩先画、换管线断批、受光标记、参数、光照开关、坏灯过滤、后处理的跳过和中间纹理轮换、换代清缓存、场景里遮罩的优先级、灯的偏移和画的位置、默认参数、去掉 `unlit`、后处理钩子，都有测试报错。
- 还没手测：金币的亮光、闪白、传送门的样子，第三关夜里的灯光和暗角，后处理开着时的帧率（尤其 iPhone），第一次用到某个着色器时编译会不会卡一下。

## 修过的问题

- 着色器自己声明 `@group` / `@binding`、`override` 时 naga 校验能过，建管线却失败，用到它的那一帧整个命令缓冲作废，所有东西都画不出来。现在校验时一并拒掉，按原样画。
- 同 z 的精灵按管线号排序，管线号又按着色器第一次用到的先后分，换代或者生成顺序一变，重叠的精灵会上下跳。现在管线号只用来断批，不参与排序。
- `Lighting2d::default()` 的环境光是黑的，Rust 里只写 `enabled: true` 会让受光的精灵全黑；改成白的。
- 跟着精灵的灯没排在名字牌跟随、相机之后，可能慢一帧；跟带视差的精灵时用的是没挪过的位置。都改了。
- 遮罩和被遮的精灵不在同一层时被遮的悄悄不见，现在 warn 一次。
- 关掉后处理以后离屏纹理还占着显存，现在放掉。
- 内置的 `pixelate` 取样点正好在两个像素中间，被线性采样平均了；改成取格子中间那个像素。
- 文档说报错的行号对的是游戏写的那段，其实是附一句从第几行开始；两层渲染器各报一次。按实际写了。
- 有两个场景测试分不清「整份场景解析失败」和「写错的字段被忽略」，改成上一份和这一份不一样的值。
