# 瓦片地图

> 前置：M3（TSX 声明式场景）、2D 物理（[physics2d.md](physics2d.md)）、相机（[camera.md](camera.md)）。

## 目标

TSX 用一个数组声明一整张关卡：按图集的格子画出来，指定哪些格子是实心的，实心格子自动变成静态碰撞体，刚体能站在上面、撞上去会发 `collide`。

**验收标准**：`examples/physics` 的地面和墙改成瓦片地图，中间加几块平台；箱子和弹球能落在平台上，撞到地图时 HUD 的碰撞次数照样增加。

## TSX

```ts
tilemaps: [{
  id: "level",
  texture: "tiles",        // 注册的图集名，或 asset:/ 路径配 grid
  grid?: [cols, rows],     // asset:/ 贴图的格子数（和精灵一样）
  tile: 32,                // 每格的边长（世界坐标）
  cols: 20,                // 每行几格
  data: [ … ],             // 一行一行从上往下，每格是图集里的帧号，负数是空格
  x?: 0, y?: 0,            // 地图左上角的世界坐标（y 朝上，行往下排）
  z?: 0,
  solid?: [0, 1, 2],       // 哪些帧号是实心的（碰撞体），不写就都不碰撞
  friction?: 0.5, restitution?: 0,
  collide?: false,         // 实心格子被撞时发 collide（另一方开了 collide 也会发），名字是地图的 id
}]
```

- `cols`、`grid`、`data`、`solid` 都要是整数（`cols` 不能是负数），不然整份 `scene` 解析失败（和别的字段一样，只记 warn）。
- 帧号超出图集的格数时按格数取模（和精灵一样）；`solid` 里写负数不起作用。
- 格子 `(列 c, 行 r)` 的中心在 `(x + (c + 0.5) × tile, y − (r + 0.5) × tile)`。
- `data` 的长度不是 `cols` 的整数倍时，最后不满一行的格子不画，记 warn；`cols` 是 0、`tile` 不是正数时整张地图不画，记 warn。
- `texture` 不是图集时每格都画整张图，记 warn。
- 地图节点里任何字段变了，整张地图重建（所有格子和碰撞体重新生成）。一次改几格（比如打碎砖块）也是重建：100×100 的地图重建一次是一万个实体，偶尔改没问题，不要每帧改。
- `collide` 事件里地图那一方的名字是地图的 `id`，另一方是精灵的 `id`；撞到地图的哪一格不报。一个精灵同时碰到地图的好几块（比如在墙角）只算一次接触：第一次碰到发 `started`，一块都不碰了才发 `stopped`。地图重建时每个正在接触的精灵可能各多收到一对 `stopped` / `started`。
- 地图和精灵的 id 各用各的空间，但 `collide` 只报名字：要分清就别让精灵和地图重名。
- 地图不能点（没有 `tap`），也不能 `tween`。

## 实现

- 新文件 `crates/nge-scene/src/tilemap.rs`，`sync_tilemaps` 和别的节点一样用 `sync_list` 按 id 增量同步。地图节点自己是一个只有 `SceneId` / `Declared` 的实体，格子精灵和碰撞体是它的子实体（`ChildOf`），删地图时一起删；节点变了先删掉所有子实体再重新生成。
- 格子精灵没有 `SceneId`，所以 `tween`、相机 `follow`、点击这些按精灵 id 找实体的地方都找不到它们。
- 碰撞体：每行先切成尽量长的横条，再把上下起始列和宽度都一样的横条并成一块，每块一个只有 `Collider` 的实体（物理层把它当固定碰撞体）。横条优先，所以平地永远是一整块，刚体沿地面滑不会碰到接缝；墙这种竖条照样并成一块，只是到地面那一行就停下（那一行归地面）。
- `collide` 事件：碰撞体实体带 `TileSolid` 标记，转事件时通过它的 `ChildOf` 找到地图；按（地图, 另一方）记着正在接触的碰撞体，从没有到有、从有到没有时才发事件。碰撞体删掉以后（重建）靠记下的归属找到地图，保证 `started` / `stopped` 配对。

## 不做

- 只重建改了的格子、按屏幕裁剪不画看不见的格子：地图很大时再做。
- 斜坡、单向平台、每格不同的材质、动画瓦片、点击某一格：需要时再加。
- Tiled（`.tmx` / `.json`）导入：数据格式简单，游戏自己转成 `data` 就行。
