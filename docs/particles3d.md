# 3D 粒子和拖尾

> 前置：2D 粒子（[m5-extensions.md](m5-extensions.md)）、基础 3D（[m4-3d.md](m4-3d.md)）、3D 和精灵混排（[3d-more.md](3d-more.md)）。

## 目标

粒子现在只有 2D：发射器跟着 `Transform2d`，粒子是平面上的精灵。3D 场景里的火、烟、火花、魔法光点没法做，跑得快的东西后面也拖不出一条尾巴。

**验收标准**：
- 3D 粒子发射器：跟着实体的 `Transform3d`，朝一个方向的锥形里发射，有重力、大小和颜色随寿命变化，粒子是朝着相机的方片（billboard）。
- 混合方式两种：普通透明（按离相机的远近从远往近画）和叠加（火、光点，不用排序）。
- 拖尾：跟着实体走，留下一条朝着相机的带子，越老越细、越淡，过了寿命消失；实体不动时尾巴慢慢缩回去。
- 粒子和拖尾被模型挡住（深度测试），自己不挡别的（不写深度）。
- 场景里能声明 3D 发射器，模型能带拖尾。
- 平台跳跃：塔边一堆 3D 篝火，箱子被撞飞时拖出一条尾巴。

## 做法

### `nge-render3d`：画（`billboards.rs`）

- `Blend`：`Alpha`（默认）、`Add`。
- `Billboards` 资源：这一帧要画的方片和带子，每帧 `PreUpdate` 清空（和 2D 的 `SpriteInstances` 一样）。
  - `push(texture, blend, Billboard { position, size, rotation, color })`、`extend(...)`。
  - `ribbon(texture, blend, points)`：一条带子，`RibbonPoint { position, width, color }`，至少两个点才画。
- 每帧在 CPU 上展开成三角形（顶点：位置、uv、颜色），一次写进一个顶点缓冲：
  - 方片：以 `position` 为中心，边长 `size`（沿相机的右、上方向各展开 `size / 2`），再绕视线转 `rotation`。
  - 带子：每个点往「切线 × 指向相机的方向」两边各展开 `width / 2`（负宽当 0），相邻两点连成两个三角形；u 按走过的长度从 0 到 1（全重合时按点的序号），v 横跨 0 到 1。切线是前后两边第一个不重合的点的差（两头用相邻的点）；切线和视线平行（带子正对相机）的点不展开。
  - 透明的方片和带子（一条带子整体算一个，按点的平均位置）按离相机的远近从远往近排，相邻同贴图的合成一次 draw；叠加的按贴图分组，画在透明的后面。
  - 离相机的远近：沿相机朝向的距离（正交相机也对）。
- 画在网格渲染器的同一个 pass 里，不透明网格之后：深度测试、不写深度；颜色 = 贴图 × 顶点颜色，不受光照。
  - 自己的管线（透明、叠加各一条）和一个只放 `view_proj` 的 uniform；贴图的 bind group 和网格共用缓存。
  - 管线随网格的一起建（跟着管线预热）。
- 和精灵混排（`interleave`）时，精灵在 3D 之后画，粒子不写深度，所以精灵会盖在粒子上面，不管谁在前。

### `nge-particles`：模拟（`emitter3d.rs`、`trail.rs`）

- `ParticleEmitter3d`（`#[require(Particles3d)]`）：
  - `rate`、`burst`、`lifetime`、`speed`、`size`、`color`、`max`、`despawn_when_done`，意思和 2D 的一样。
  - `direction: Vec3`（本地坐标，随实体旋转，默认朝上）、`spread`（锥形的半角，弧度，默认 π，全方向）：方向在锥形里按立体角均匀取。
  - `gravity: Vec3`（世界坐标）、`texture: ImageId`、`blend`。
  - `spin: (f32, f32)`：方片转动的角速度（弧度 / 秒），出生时随机取一个。
- 粒子在世界坐标里，发射后不跟着发射器走。
- `Trail3d`（`#[require(TrailPoints)]`）：
  - `lifetime`（秒，默认 0.5）、`width: (f32, f32)`（新、旧两头的宽）、`color: (Vec4, Vec4)`、`min_distance`（离上一个点多远才记一个新点，默认 0）、`max_points`（默认 64）、`texture`、`blend`。
  - 每帧记下实体当前的位置（离上一个点不到 `min_distance` 时只挪最新的点；实体没动时只把最新的点年龄归零，不叠重合的点），过了寿命的点丢掉；带子最新的一头总是在实体当前的位置。
  - 宽和颜色在两头之间插值，比例取「年龄 / 寿命」和「序号 / (max_points − 1)」里大的那个：点数到上限时尾巴也收到旧的那头，不在截断处突然断掉。
  - `TrailPoints::clear()` 清掉记下的点（实体瞬移后用）。
- `Particles3dPlugin`：在 `PostUpdate` 里注册这两个系统（`Particles3dSimulated` 集合）；要加在 `Render3dPlugin` 之后（没有 `Billboards` 时直接报错）。
- 改 `Transform3d` 的系统（物理、跟随、场景的 `attach`）要排在 `Particles3dSimulated` 前面，拖尾才跟得上这一帧的位置；场景插件排好了。

### `nge-scene` 和 TSX

- `emitters3d: Emitter3dNode[]`：
  - `id`、`x` / `y` / `z`、`rate`、`lifetime`、`speed`、`direction: [x, y, z]`（默认朝上）、`spread`（度，默认 180）、`gravity: [x, y, z]`、`size`、`color`、`spin`（度 / 秒）、`texture`、`blend: "alpha" | "add"`、`max`。
  - 只改参数、没换贴图时保留已经发射出去的粒子。
- `App` 加 `configure_sets`，场景插件把 `Particles3dSimulated` 排在 2D / 3D 物理、`attach`、`follow` 之后。
- `ModelNode.trail?: TrailNode`：`lifetime`、`width: [新, 旧]`、`color: [新, 旧]`、`minDistance`、`maxPoints`（默认 64）、`texture`、`blend`。去掉 `trail` 时尾巴马上消失；只改参数时保留已经记下的点；有刚体的模型重新声明了位置（瞬移）时清掉记下的点，不拉出一条横穿画面的带子。没有刚体的模型每帧改位置就是在动，照常拖尾。
- 自己补上 `Particles3dPlugin`。

### 示例（平台跳跃）

- 第一关那摞箱子右边一堆篝火（`campfireAt`）：叠加混合的火苗往上飘、转着变小，和箱子在同一个深度，箱子飞到前面时挡住它。
- 那摞 3D 箱子都带一条淡黄色的叠加拖尾（`minDistance` 2）：摞着不动时只有一个点、画不出来，被撞飞时拖出尾巴。

## 不做

- GPU 上模拟粒子、粒子之间排序以外的透明排序（和半透明网格的混排放到第 14 项）。
- 软粒子（靠近表面淡出）、粒子受光照和投影子、粒子碰撞。
- 网格粒子（每个粒子是一个模型）、序列帧动画粒子、速度方向拉长的粒子。
- 发射器形状（球面、盒子、网格表面）：只有点加方向锥。
- 精灵和粒子之间的深度：精灵总在粒子上面。
- 按距离判断瞬移：只有场景里「有刚体的模型重新声明位置」算瞬移；自己写系统挪 `Transform3d` 的，要瞬移时自己调 `TrailPoints::clear()`。
- 每帧的分配：排序用的数组和带子的点每帧新建，粒子几百个以内不成问题，以后要再复用。

## 验收

- `billboards` 单元测试：方片朝着相机、绕视线转、边长对；透明的从远到近、叠加的在后面按贴图分组、相邻同贴图合批、混合不同不合；带子往两边展开、中间按前后切线、拐弯斜 45°、透视下往相机偏、正对相机不出 NaN、u 按长度；重合的点找不重合的邻居、负宽当 0、全重合不出 NaN；带子按中点和方片一起排。
- 离屏测试（有 GPU 时）：被前面的方块挡住；叠加的两层颜色相加、不写深度；透明的按透明度混合；带子画出一条横带。
- `emitter3d` 单元测试：方向在锥形里按立体角均匀；锥角超过 π 和 NaN 当全方向；零向量方向当 +Y；随实体旋转；重力、大小插值、转动、上限、一次性的放完自动删；每帧清空后重新放。
- `trail` 单元测试：记下走过的点、过寿命的丢掉、最新的点不算老；不动时尾巴缩回一个点；先动后停时不叠重合的点、最新一头还是最宽；`min_distance` 只挪最新的点；点数上限和到上限时渐细；`clear`。
- 场景：`emitters3d` 生成发射器、只改参数时保留粒子、换贴图重来、去掉时删；模型的 `trail` 加上、只改参数时保留点、`maxPoints` 透传、去掉马上消失；有刚体的模型重新声明位置时清掉点；节点的默认值。
- 平台跳跃：`App.test.tsx` 里篝火在箱子同一个深度、叠加混合、往上飘，箱子带着拖尾。
- 变异检查：透视的指向相机、带子按中点排、中间的切线、叠加乘透明度、选管线、每帧清空、立体角均匀、锥角上限、随实体旋转、重力、大小插值、上限、自动删、保留最新点、间距看上一个点、不动不开新点、点数上限、宽度插值、老化、换贴图重来、去拖尾、锥角和转速的度数、停下不叠点、上限渐细、`clear`、重合找邻居、负宽、按长度的 u、NaN 锥角、`maxPoints` 透传、瞬移清点，改掉都有测试报错。
  - 等价的一处：零向量方向不先换成 +Y 时，glam 的 `from_rotation_arc(Y, 0)` 本来就给单位旋转，结果一样。
- 还没手测：篝火和拖尾在 Mac 和 iPhone 上的样子、叠加混合在亮背景上的效果、箱子撞飞时尾巴的长短。

## 修过的问题

- 实体停下时每帧叠一个和最新点重合的点，重合的点算不出切线，最新一头的宽收成 0：现在不动时只把最新点的年龄归零，带子的切线也会跳过重合的邻居。
- 有刚体的模型被场景重新声明位置（比如重开一关）时，拖尾从旧位置拉出一条长带子：现在会清掉记下的点。
- 点数到上限时最老的点直接截掉，高帧率下尾巴在截断处还很宽：插值比例也看点的序号。
- 负的宽度会让带子两边翻过来、NaN 的锥角会让方向变成 NaN：负宽当 0，NaN 当全方向。
- 带子的 u 按点的序号算，点疏密不匀时贴图被挤：改成按长度。
- `Billboards::len` 只数方片、名字容易误会，改名为 `quads`。
