# 寻路和 AI：格子 A*、状态机、追击

> 前置：瓦片地图（[tilemap.md](tilemap.md)）、2D 物理（[physics2d.md](physics2d.md)）。

## 目标

敌人现在只能靠补间来回巡逻，碰到墙也不会绕。游戏想做「看见玩家就追、追丢了回去」的敌人，只能自己写寻路和状态切换。

**验收标准**：
- 在格子上找路：绕开实心格子，不从两个实心格子的墙角挤过去；路径拉直，不走锯齿。
- 一个通用的小状态机，记着现在的状态和进了这个状态多久。
- 场景里的精灵写 `chase`，就会在瓦片地图里绕开墙追目标；追太远了回到出发点。状态变了发 `chase` 事件。
- 平台跳跃里有会飞的幽灵追玩家。

## 做法

### 新 crate `nge-ai`

只依赖 `nge-ecs`、`nge-render2d`（`Transform2d`）、bevy_ecs、glam。

#### 格子（`grid.rs`）

- `Grid { cols, rows, blocked }`：一行一行从上往下，格子用 `(列, 行)`。地图外面算挡住。
- `find_path(grid, from, to) -> Option<Vec<(列, 行)>>`：A*，八个方向，斜着走算 √2。
  - 斜着走时旁边两格都要是空的（不切墙角）。
  - 起点或终点挡住了、走不到，返回 `None`；最多展开 `MAX_EXPANDED`（4096）个格子，超过也算走不到，免得大地图上卡一帧。
  - 只记碰到过的格子（`HashMap`），开销跟着展开的格子数走，不跟地图大小走。
  - 起点就是终点时返回只有它的路径。
- `clear(grid, a, b, radius)`：从 `a` 到 `b`（格子坐标，可以带小数）走直线，半边长 `radius` 的方块一路上碰不碰到挡住的格子。按 0.1 格一步取样，方块更小时按它的半边长取（最小 0.01 格）。
- `smooth(grid, path, radius)`：拉直。从当前点往后，一直能直线走到的就接着往后看，走不通了就在上一点拐弯。

#### 状态机（`fsm.rs`）

- `Fsm<S>`：现在的状态和进了这个状态多久。
  - `tick(dt)` 累加时间。
  - `go(s)`：换了状态才把时间清零，返回换没换。

#### 导航网格和追击（`chase.rs`）

- 组件 `NavGrid { grid, origin, tile }`：格子摆在世界里的样子，`origin` 是左上角。
  - `cell(世界坐标)`、`center(格子)` 互相换算。
  - `path(从, 到, radius)`：找路、拉直，换成世界坐标；第一个点是下一步要去的地方，最后一个点就是 `到` 本身。
    - 能从起点直线走到下一点就不先回起点格子的中心。
    - 最后一段走不通（目标贴着墙）时先经过终点格子的中心。
  - `sees(a, b)`：两点之间有没有墙挡着，视线按 0.05 格粗算，斜着穿过两块墙的墙角算挡住（和找路一致）。
- 组件 `Chaser`：
  - 参数：`target`（实体）、`speed`、`sight`（多远能看见）、`leash`（离出发点多远就不追了）、`home`（出发点）。
  - 状态 `ChaseState`：`Idle`（在家）、`Chase`（追）、`Return`（回家）。
- 系统 `chase`（`Update`）每帧：
  - `Idle`：目标在 `sight` 以内，并且中间没有墙挡着（`sees`），开始追。刚回到家要歇 1 秒（`REST`），免得在追得到和追不到的边上来回折腾；一开始是歇够了的。不在家（被挪走了）就回家。
  - `Chase`：目标没了、跑出 `sight` 的 1.5 倍、自己离家超过 `leash`，就回家；重新找路时找不到，当帧就回家。
  - `Return`：走完路线、到家（2 像素以内）就回到 `Idle`。找不到回家的路就直线飘回去。
  - 追的时候每 0.3 秒重新找一次路（`REPLAN`）；回家只在开始回家时找一次。
  - 沿路径按 `speed` 直接挪 `Transform2d`，这一帧剩下的路程接着走下一段。
  - 在哪张 `NavGrid` 里由自己的位置决定（重叠时取先找到的那张）；不在任何一张里时直线走过去。
  - 状态变了发消息 `ChaseChanged { entity, state, at }`，`at` 是变的时候在哪。
  - 目标不能是另一个 `Chaser`（查目标时排除了追击的角色），指过去当作没有目标。
- 碰撞的半径固定按 0.4 格（`AGENT_RADIUS`），适合比一格小一点的角色。

### 场景（`nge-scene`）

- `SpriteNode.chase?: { target, speed?, sight?, leash? }`，默认 120 / 240 / 480 像素。
  - 新加了 `chase` 或位置变了才重新建 `Chaser`（出发点是声明的位置）；只改了 `chase` 的参数时原地换掉，接着追；别的属性变了不碰。去掉就删。
  - 有 `chase` 时位置和有刚体时一样归它管：声明的位置没变就不拉回去。
  - 目标按场景 id 找，每帧对一遍（目标重建了也跟得上）。
- 瓦片地图把实心格子做成 `NavGrid`，挂在地图实体上。没有实心格子的、带视差的地图不挂（装饰层不该让角色以为一路畅通）；地图改得不合法时删掉。
- 事件 `chase`：`{ id, state: "idle" | "chase" | "return", x, y }`。
- 追击的精灵配 `kinematic` 刚体：`Transform2d` 是物理的目标，不会被墙挡住，路线本身绕开了墙。

### TSX

- `SpriteNode.chase`、事件 `chase`（`ChaseEvent`）。

### 示例（平台跳跃）

- 前两关各有一只幽灵（id 以 `enemy-` 开头，踩它和碰它跟别的敌人一样）。玩家靠近就绕开平台追过来，追丢了飘回去。
- 开始追时头上飘「!」，放弃时飘「?」。

## 不做

- 行为树。状态机够用的时候不加；要做复杂的 AI 时再说。
- 走地面的寻路（要算跳跃、下落的连线）。现在只有会飞的能用格子寻路。
- 导航网格（多边形）、群体避让、流场。
- 移动的平台、箱子这类动态障碍不进格子。

## 验收

- `nge-ai` 单元测试：
  - A* 绕墙、最短、不切墙角；起点 / 终点挡住、被围住、超过展开上限都是 `None`；起点就是终点。
  - `clear` 擦着墙角时按半径算挡住；`smooth` 空旷处拉成一段、拐弯处留下拐点。
  - `Fsm` 换状态才清零。
  - `NavGrid` 坐标换算；`Chaser` 看见才追（墙后面看不见）、绕墙追上、超出距离回家、到家回到 `Idle`、每次换状态发一条消息；斜着的墙角看不见也找不到路、每一段（包括最后一段）都按半径走得通；回家后歇一会儿才再追；不在家的 `Idle` 回家、绕墙回家。
- `nge-scene`：`chase` 节点建出 `Chaser`、目标按 id 找到；改颜色不重置也不拉回、只改参数原地换、去掉就删；只有有实心格子、不带视差的瓦片地图有 `NavGrid`，改得不合法时删掉；状态变了发 `chase` 事件。
- 平台跳跃：幽灵在玩家走近后才追，飞过来撞到玩家。TSX 测试检查各关的幽灵都在空格子里。
- 变异检查：改掉不切墙角、启发函数、展开上限、看见的判断、各个状态切换、重新找路、沿路径走的剩余路程，都有测试报错。
  - A* 里跳过过期的点只省时间、不改结果，没有测试。
  - 回家只找一次路：重新找也是同一条路，没有测试。
  - 回到 `Idle` 前要走完路线：`Idle` 也会把剩下的路线走完，结果一样。
  - `chase` 和位置都没变时直接跳过：不跳过也是原地换参数，结果一样。
- 还没手测：平台跳跃里幽灵追人的样子。

## 修过的问题

- 回家时离出发点 2 像素就停下，差最后一点；改成走完路线才回到 `Idle`。
- `chase` 事件的位置是这一帧走完之后的；改成状态变的那一刻的位置，头上飘的字对得上。
- 只改 `chase` 的参数时重建成 `Idle`，停在半空不回家；没刚体的追击角色改颜色时被拉回出发点、却还沿着旧路线飞。改成参数原地换、位置不拉回、`Idle` 不在家就回家。
- 视线按 0.1 格取样，斜着穿过墙角时算看得见、找路却找不到，状态每两帧来回切、头上不停飘字。视线改成按小方块算墙角；回到家歇 1 秒再追。
- 每张瓦片地图都挂导航网格，追击的角色可能用上装饰层那张全空的、穿过地面；改成只给有实心格子、不带视差的地图。
- A* 每次按整张地图分配数组，拉直对每个点从末尾往回试；改成只记碰到过的格子、拉直一遍往前推。
- 走到目标的最后一段没按半径检查，贴墙的目标会让角色压进墙里；改成走不通时先经过终点格子的中心。
