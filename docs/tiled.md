# Tiled 地图导入

> 前置：瓦片地图（[tilemap.md](tilemap.md)）、视差背景（[parallax.md](parallax.md)）、关卡切换（[levels.md](levels.md)）。

## 目标

现在关卡要手写 `data` 数组，或者像平台跳跃那样用代码生成。画关卡的人更习惯用 [Tiled](https://www.mapeditor.org/)：画图块层，在对象层里摆金币、敌人、出生点。

**验收标准**：
- TSX 直接 `import` Tiled 存的 JSON 地图，`tiled(map, { textures })` 转出 `tilemaps` 和对象列表，放进场景就能玩。
  - 每个图块层一张瓦片地图，实心的图块按图块集里的属性。
  - 对象换成世界坐标，游戏按类型生成精灵。
  - 不支持的地图（无限、外部图块集、压缩数据、等角）报错，说清在 Tiled 里怎么改。
- 平台跳跃加第三关，用 Tiled 格式的地图文件。

## 做法

在 TSX 里转，不进引擎：

- 关卡流程和状态机在 TSX（见 engine-design.md 的关键设计决策 2），对象生成什么由游戏决定，转换放在 TSX 最直接。
- nsh 能直接 `import map from "./level3.json"`，带类型，打进包里，不用另外加载资源。
- 引擎的瓦片地图协议不用改，转出来的就是普通的 `TilemapNode`。

新文件 `ts/tiled.ts`，导出 `tiled(map, options)`：

```ts
import level3 from "./maps/level3.json";
const { tilemaps, objects, width, height } = tiled(level3, {
  textures: { tiles: "asset:/@platformer/tiles.png" },  // 图块集名 → 图集
  x: 0, y: 448,                                         // 地图左上角的世界坐标，默认 (0, 0)
  prefix: "l3-",                                        // 加在瓦片地图 id 上
});
```

### 图块层

- 每个可见的图块层一张瓦片地图：id 是 `prefix + 图层名`，`tile` 是瓦片边长，`cols` 是图层宽。
- 格子里的 gid 减去图块集的 `firstgid` 就是图集帧号，0（空）变成 -1。
- `grid` 是图块集的 `[columns, tilecount / columns]`。
- 一层只能用一个图块集（引擎的瓦片地图只有一张图集），用了好几个时报错。
- 翻转、旋转的瓦片按不翻转画，每层警告一次。
- **实心**：图块集里布尔属性 `solid` 为 true 的图块。图层的布尔属性 `solid` 为 true 时整层实心，为 false 时整层不实心（用同一套图块画的背景层）。
- **图层属性**：`z`、`friction`、`restitution`、`collide` 照抄到瓦片地图上。
- **偏移和视差**：图层的偏移（`offsetx` / `offsety`）加到位置上；Tiled 的视差系数（`parallaxx` / `parallaxy`）变成 `parallax`。组图层的偏移和子图层相加，视差相乘。
- **视差的参照点**：Tiled 画视差层时按「视野中心 − 参照点」挪（参照点默认是地图左上角，再加地图的 `parallaxoriginx` / `parallaxoriginy`），引擎按「相机位置 − 世界原点」挪。转换时把差的 `参照点 × (1 − 系数)` 从位置里减掉，相机对准同一处时两边画的一样。
- **图块集**：只支持一张图、边距和间距为 0 的图块集；图像集合（`columns` 是 0）报错。瓦片编号超出图块集时报错。
- 隐藏的图层跳过。

### 对象层

对象不直接变成精灵，转成一份列表，游戏自己决定生成什么：

```ts
interface MapObject {
  id: number; name: string; type: string; layer: string;
  x: number; y: number;          // 中心，世界坐标（y 朝上）
  w: number; h: number;
  rotation: number;              // 度，逆时针为正（和精灵一样）
  point: boolean; ellipse: boolean;
  properties: Record<string, unknown>;
}
```

- `type` 取 Tiled 的类型：Tiled 1.10 写在 `type` 里，1.9 写在 `class` 里；`type` 是空字符串时看 `class`。
- 多边形、折线给点的外接框（旋转前的），中心按 Tiled 的转法算。
- 用了对象模板的对象报错：类型和大小在外部 `.tx` 文件里。
- 对象不跟着图层的视差。
- Tiled 里 y 朝下、对象的 (x, y) 是左上角（图块对象是左下角），旋转绕这个点、顺时针为正。转换时算出旋转后的中心，角度取反。
- 隐藏的对象跳过。

### 报错

不支持的东西直接抛 `Error`，消息以「Tiled 地图：」开头，说清怎么改：

- 无限地图：在地图属性里关掉「无限」。
- 外部图块集（`.tsx`）：在 Tiled 里把它嵌入地图。
- base64 / 压缩的图层数据：把地图属性的「图层格式」改成 CSV。
- 不是正交的地图、瓦片不是正方形。
- 用到了 `textures` 里没给的图块集。

### 平台跳跃

- 第三关「云端」`maps/level3.json`：Tiled 1.10 的 JSON 格式，图块集嵌在里面，图块 0–2 和 `tiles.png` 一样，`solid` 属性标在三种图块上。
  - 图层 `ground`：地面、坑、平台、台阶，属性 `friction = 0`。
  - 图层 `far`：远处的云，Tiled 的横向视差 0.5，属性 `solid = false`、`z = -3`。
  - 对象层 `things`：金币（`coin`，点）、敌人（`enemy`，点，属性 `patrol` 是往右巡逻几格）、移动平台（`lift`，64 × 16 的矩形，属性 `dx` / `dy` 是往哪走的像素、只给一个，`duration`）、3D 箱子（`crate`，点）、终点（`goal`，矩形）。
- 摆法和前两关一样：坑边正上方不放平台，移动平台左缘对齐坑的左缘、走到头右缘对齐坑的右缘；云都在地图的前一半（视差 0.5 的层，相机走到最右时也只露出前一半）。
- `levels.ts` 的 `fromTiled(map)` 把它转成和代码描述的关卡一样的 `Built`，后面的流程不变。地图底行的顶边放在 y = 0。
- `LEVELS` 现在是「名字 + 生成好的关卡」，代码描述的两关和 Tiled 的一关排在一起，存档、选关（数字键 3）照旧。

## 不做

- 引擎里加载 `.tmx` / `.tmj`：TSX 转就够了，需要运行时下载地图时再说。
- 外部图块集、图像集合、有边距和间距的图块集、无限地图、压缩数据、等角和六角地图、一层多个图块集、图块动画、瓦片翻转、图像层、多边形和折线的形状（只给外接框）、对象模板。
- 图块集的 `objectalignment` 不是默认值时，图块对象的锚点不按它算（一律按左下角）；图块对象也不继承图块的类型。
- 文本对象：当普通对象转出来，文字和样式不管。

## 验收

- `tiled.test.tsx`（`nsh test`）：
  - 图块层：帧号从 0 数、空格是 -1、实心按图块属性，位置按地图左上角。
  - 对象：中心、y 朝上；点对象；图块对象按左下角；转了 90° 的矩形按 Tiled 的转法算中心，角度取反；隐藏的跳过。
  - 图层属性：整层实心、整层不实心、`z`、`collide`，组图层和子图层同一个轴都有值时偏移相加、视差相乘，前缀；隐藏的层跳过。
  - 视差的参照点：地图有 `parallaxorigin`、`options` 有偏移时，相机对准参照点时画回 Tiled 里的位置。
  - 对象：`type` 是空的看 `class`；多边形、折线的外接框。
  - 报错：无限、等角、瓦片不是正方形、外部图块集、图像集合、有间距、瓦片超出图块集、对象模板、base64、一层多个图块集、没给图集。
  - 第三关：两层瓦片地图（地面实心、云不实心带视差），10 个金币、3 个敌人、1 块移动平台、箱子和终点的位置。
  - 变异检查：角度不取反、整层不实心不起作用、不去掉翻转标记、图块对象按左上角算、横向或竖向不换算视差参照点，都有测试失败。
- **修过的问题**：第三关的移动平台偏左一格，走到头够不着对岸；第一个坑的起跳边正上方压着平台，起跳的窗口太窄；远处的云有两组永远看不到；视差层没按 Tiled 的参照点换算；图像集合的图块集让整份场景解析失败；组图层的测试分不出相加和继承；多边形和折线没给外接框；Tiled 1.10 的空 `type` 盖住了 `class`；用了模板的对象被悄悄转成空的；翻转标记少清了一位；悬空的金币太高，满跳只擦到一点。
- 还没手测：Mac 上第三关的画面（云的视差、平台位置）、走一遍能通关。
