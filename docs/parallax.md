# 视差背景

> 前置：2D 相机（[camera.md](camera.md)）、瓦片地图（[tilemap.md](tilemap.md)）、2.5D 相机（[camera25d.md](camera25d.md)）。

## 目标

平台游戏的背景常分几层：远山慢慢动，近处的树快一点，前景比关卡还快。现在精灵都钉在世界坐标上，相机走多少它们就在屏幕上挪多少，做不出层次。2.5D 场景里还有一个问题：精灵总画在 3D 模型上面，背景会盖住模型。

**做两件事：**

**1. 视差。** 给精灵和瓦片地图加 `parallax`，表示相机移动时这一层跟着移动的比例。

| `parallax` | 效果 |
|---|---|
| 1（默认） | 和关卡一样，钉在世界里 |
| 0.5 | 相机走 100，它在屏幕上只挪 50，像远处的东西 |
| 0 | 钉在屏幕上，相机怎么走都不动 |
| 1.5 | 比关卡挪得快，像镜头前的前景 |
| `[0.3, 1]` | 横向和竖直分开设：横向慢慢挪，竖直方向跟着关卡。横版背景大多这样设，跳起来时远山不会跟着往下沉、离开地面 |

**2. 背景层。** z < 0 的精灵画在 3D 模型后面，点击时也排在模型后面。z ≥ 0 的精灵还是画在模型上面。

**验收标准：**
- 平台跳跃加两层背景：远山 `[0.2, 1]`，近处的树 `[0.5, 1]`。跟着角色跑时，远的动得慢、近的动得快，竖直方向都立在地上，终点前的 3D 箱子在它们前面。
- 点视差精灵时，按画面上看到的位置算（`tap` 打得中）。
- 坏值（NaN、无穷）按 1 处理，并且报 warn。

## 做法

**画的位置** = 声明的位置 + 相机位置 ×（1 − `parallax`），x、y 分开算。

- **推导**：屏幕上的位置是「画的位置 − 相机位置」，代进去得到「声明的位置 − 相机位置 × `parallax`」。所以相机挪 d 时，这一层在屏幕上挪 `parallax` × d。
- **怎么摆**：相机在原点时，所有层都画在声明的位置上。摆的时候按相机在原点来摆；竖直方向设成 1 的话，竖直方向就按关卡的坐标摆。
- **`drawn()`**：`nge-render2d` 加 `Parallax(Vec2)` 组件，以及算画在哪的 `drawn()`。它同时考虑刚体插值（`DrawAt`）和视差。渲染和点击都用它，所以两边不会对不上。
- **缩放、旋转、震屏**：相机的缩放、旋转和震屏照常作用在所有层上。震屏时相机的位置在抖，视差层抖得少一些（乘 `parallax`），远景本来就该这样。
- **精灵**：`scene.sprites[].parallax` 写一个数或者 `[x, y]`，同步时加上或去掉 `Parallax`。设了视差又有 `body` 时报 warn：碰撞体和物理调试的轮廓都在声明的位置，和画面对不上。
- **瓦片地图**：`scene.tilemaps[].parallax` 加在地图的每个瓦片精灵上。碰撞体还在声明的位置，所以有实心格子又设了视差时报 warn。

**背景层**：

- 精灵渲染器拆成两个。z < 0 的那个用 `App::prepend_renderer` 排在所有渲染器前面，在 3D 之前画；没有背景精灵时不开 render pass。其余精灵排在 3D 后面画。粒子之类的额外实例按同样的规则分层。
- 只有 2D 的场景里，背景层先画、其余后画，和以前按 z 排序画出来一样。
- 点击按画的顺序从上往下找：z ≥ 0 的精灵、3D 模型、z < 0 的精灵。

## 不做

- **背景横向无限重复**：现在要在 TSX 里多摆几张。以后可以给精灵加 `repeat`。
- **其他东西的视差**：文字、粒子、3D 模型都不加视差。
- **跟随视差精灵**：相机跟随视差精灵时，`follow` 用的是声明的位置，结果不对，这么做也没有用处。
- **按距离缩放**：视差层不会按远近自动变小，要的话手动设 `scale`。
- **Update 里挪相机**：在 `Update` 里、点击处理之前挪相机的系统，会让视差精灵的命中偏 Δ相机 ×（1 − `parallax`）。指针的世界坐标在 `PreUpdate` 里就按当时的相机算好了；同帧要改相机的系统本来就该排在 `PointerWorld` 前面。

## 验收记录

- `cargo test --workspace` 通过：
  - `drawn()`：视差层在画面上挪的距离是关卡的 `parallax` 倍（相机带缩放和转角），x、y 分开，和刚体插值叠加，坏值按 1。
  - 离屏渲染：视差精灵画在 `drawn()` 算的位置；z < 0 的精灵在 3D 模型下面、模型外面露出来。
  - 场景：`parallax` 写一个数或 `[x, y]`、去掉时移除、无穷大不加；瓦片地图每个瓦片都加、碰撞体不加；点视差精灵按画的位置（场景声明的相机和 Rust 直接改的相机都对）；和模型重叠的背景精灵点不到、模型外面点得到。
  - 变异检查：视差偏移除以缩放、渲染不算视差、点击不算视差、去掉声明时不移除组件、坏值不按 1、背景层不排在最前，各有测试会失败。
- iOS 检查（`cargo check --workspace --target aarch64-apple-ios`）通过，平台跳跃 `nsh check` 通过。
- Mac 上 `nsh run examples/platformer` 手测：往右跑时远山挪得最慢、树稍快，竖直方向都立在地上，终点前的 3D 箱子在背景前面。

**修过的问题**：
- 背景精灵画在 3D 箱子上面，把箱子盖住了：z < 0 的精灵改成画在 3D 后面。
- 视差只有一个系数时，相机不在原点，树和远山就离地漂着：`parallax` 支持 `[x, y]`，演示的竖直方向用 1。
- 文档说坏值报 warn，代码没报；瓦片地图的 warn 对坏值误报；精灵有刚体又设视差时不提示。
- 渲染器没有测试覆盖视差；`drawn()` 只在缩放 1、不转的相机下测。
