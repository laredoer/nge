# 示例游戏：长坂坡（2.5D 横版清版动作）

> 前置：平台跳跃示例（examples/platformer）用到的全部引擎能力。

## 目标

做一款能玩的小游戏，展示 nge 在 2D 精灵和 3D 模型混排时的效果。题材取三国的长坂坡之战：玩家扮演一名白袍枪将，在曹军的追兵里一路杀到长坂桥。人物、关卡、美术、音效都是原创的，用脚本生成，不照搬任何已有游戏。

## 玩法

- **视角**：横版清版（belt scroll）。地面是一条有纵深的带子，角色能左右走，也能往里、往外走。离镜头远的画得靠上、靠后，按纵深排前后。镜头跟着玩家往右走，前面的敌人没清完时锁住。
- **操作**：
  - 方向键或 WASD：移动。
  - J：普通攻击，连按三段，第三段把敌人挑飞。
  - K：突刺，往前冲一段，一路上的敌人都受伤；有冷却。
  - L：跳跃，跳着时按 J 是下劈。
  - 暂停、重开用 P、R（和平台跳跃一样）。
- **敌人**：
  - 刀兵：走近了砍。
  - 弓兵：保持距离放箭，箭能被打掉。
  - 骑将（首领）：血厚，会冲锋，冲锋前停顿一下给玩家留反应时间。
- **流程**：三段战场，每段两三波敌人。最后在长坂桥前打首领，赢了出胜利画面，倒下了出失败画面，都能重开。
- **界面**：左上是玩家血条和怒气（突刺用），右上是斩敌数，首领出场时屏幕下方出首领血条。文案中英两套，跟系统语言。

## 画面（2.5D）

- 角色、敌人、箭、刀光是 2D 像素精灵（脚本生成的图集）。
- 场景里的立体物件是 3D 模型（脚本生成的 glTF）：城墙残段、粮车、旌旗（会飘）、拒马、长坂桥。正交相机，和精灵混排，物件挡住后面的人。
- 黄昏的光：低角度的太阳投影子，几处着火的粮车有点光源和火焰粒子，bloom 让火光和刀光往外晕。
- 远景是一层群山，背景层后处理稍微模糊。
- 打中有顿帧和屏幕震动，敌人被打时闪白，倒地以后化成烟散掉。

## 声音

- 挥枪、击中、射箭、冲锋的马蹄、胜利、失败，用脚本合成的 wav。

## 不做

- 联网对战、多人同屏。
- 存档（一局几分钟，打完重开）。
- 骑马战斗、兵种升级、技能树。
- 手机触屏操作：后来加了摇杆和按钮，见 [touch-input.md](touch-input.md)。

## 验收

- `nsh test` 覆盖：连段计时、突刺冷却和怒气、敌人状态机（追、攻击、受击、倒地）、弓兵保持距离、首领冲锋前摇、波次推进和镜头锁定、胜负判定、文案两套齐全。
- `nsh check` 通过；`cargo test -p sanguo` 通过（资源打包、模型能加载）。
- `nsh run examples/sanguo` 能从开头打到胜利画面。
- 还没手测。
