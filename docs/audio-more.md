# 音频补齐：混音分组、效果器、按位置的声音

> 前置：音频（[audio.md](audio.md)）。

## 目标

现在所有声音都直接进总输出：音乐和音效没法分开调音量，没有效果器（水下、暂停时的闷声，山洞里的回声），声音也不知道是从哪里发出来的。

**验收标准**：
- 三个混音分组：音乐、音效、界面，各自调音量。
- 每个分组可以加低通滤波和混响，参数能平滑地变。
- 声音可以带一个世界里的位置：离听的人（相机）越远越小，在左边就偏左。
- 场景里能写分组的设置，`sound` 命令能指定分组和位置。
- 平台跳跃：夜里那关的音效带回声；幽灵发现角色时，从幽灵的位置发出一声。

## 做法

### `nge-audio`

- `Bus`：`Music` / `Sfx`（默认）/ `Ui`。
  - 启动时给每个分组建一条 kira 的子轨道，上面串一个低通滤波和一个混响。
  - 低通一直是全湿，关着时截止频率在 20000（听不出来）。只调截止频率，不做干湿交叉淡变：那样中间会变响。
  - 混响一开始是干声（mix 0），等于没有；但它一直在算，三组各一个，移动端有一点固定的 CPU 开销。
  - 混响是单声道输入，加多了会冲淡按位置算出的左右。
  - 测试用的不出声后端（采样率 1）不挂混响：kira 的混响按采样率开缓冲，太小会越界。设置照样记下来。
- `Play` 多两个字段：
  - `bus`：进哪个分组，默认 `Sfx`。
  - `at: Option<Vec2>`：在世界里的位置，`None` 是不按位置（界面音、音乐）。
- `Audio` 新增的方法：
  - `set_bus_volume(bus, volume, fade)`、`bus_volume(bus)`。
  - `set_lowpass(bus, cutoff, fade)`：`Some(赫兹)` 打开低通，截止频率限制在 20 到 20000；`None` 关掉。
  - `set_reverb(bus, mix, fade)`：混响的湿声比例，0 到 1；0 等于关掉。
  - `set_listener(pos)`、`listener()`：听的人在哪。
  - `set_range(range)`：多远就听不见，默认 1000。
  - `set_voice_position(voice, pos)`：挪一个按位置的声音。
- 按位置的声音：
  - 音量乘上 `1 - 距离 / range`（这个系数截到 0 到 1）。不是有限数的音量当 0。
  - 声像 = 自己的 `pan` + 横向距离 / (range / 2)，截到 -1 到 1。
  - 开始时按当时的位置算。听的人或声音挪了，下一帧更新，用 50 ms 平滑过渡，免得爆音；游戏用 `set_voice_volume` 设的淡变还没走完时，按剩下的时间过渡，不把它缩短。
  - 算法是一个纯函数 `spatial(volume, pan, at, listener, range) -> (volume, pan)`，单独测。
- 调试和测试用：
  - `Audio::mix(voice) -> Option<(f32, f32)>`：这个声音现在的音量和声像（按位置算过）。
  - `Audio::playing()`：正在播的声音。
  - `Audio::bus_sounds(bus)`：分组的轨道上有几个声音（含正在淡出的）。

### 场景（`nge-scene`）

- `scene.audio` 多出两项：
  - `buses?: { music?, sfx?, ui? }`，每项是 `{ volume?, lowpass?, reverb? }`。`lowpass` 是赫兹，不写是关；`reverb` 是 0 到 1。变了才设，过渡 0.3 秒。
  - `range?`：默认 1000。
- 背景音乐进 `music` 分组。
- `sound` 命令多出三项：
  - `bus?: "sfx" | "ui" | "music"`。
  - `x?`、`y?`：两个都写了才按位置播。
- 听的人每帧放在 2D 相机的位置上（跟着画面中心，不含震屏）。

### TSX

- `AudioNode.buses`、`AudioNode.range`；`sound()` 的 `bus`、`x`、`y`。

### 示例（平台跳跃）

- 第三关（夜里）给 `sfx` 分组加 0.35 的混响。
- 幽灵开始追时，在幽灵的位置播一声低八度的金币声（`pitch` 0.5），左边的幽灵听起来在左边。同一只两秒内只响一次。

## 不做

- 3D 的按位置播放（按 3D 相机和距离算）：等 3D 游戏用到时再说。
- 多普勒、遮挡、按材质的混响。
- 一个声音跟着实体走：按位置的声音只在开始时定位置；要跟着走的，游戏自己调 `set_voice_position`，场景里先不提供。
- 效果器链可配置（只固定一个低通一个混响）。

## 验收

- `nge-audio`：
  - `spatial` 的衰减和声像：正中、左右、超出范围、截断、基础声像叠加。
  - 分组音量、低通、混响的设置能读回来，参数会被截到合法范围。
  - 按位置的声音开始时、听的人挪了以后，`mix` 都对；不按位置的声音不受影响；`set_voice_position` 管用。
  - 没有音频设备时这些调用都是空操作，不 panic。
- `nge-scene`：
  - `buses` 设到 `Audio` 上，去掉后回到默认。
  - 音乐进 `music` 分组。
  - `sound` 带位置和分组。
  - 听的人跟着相机走。
- 平台跳跃：TSX 测试检查夜里那关有混响、别的关没有。
- 变异检查：衰减、声像比例、NaN 位置、范围不合法、各项截断、听的人不要 NaN、排队中挪位置、不按位置的不挪、每帧更新、开始时和改音量时按位置算、进分组；场景的分组音量、低通、混响、范围、音乐和音效的分组、音效的位置、听的人跟着相机，改掉都有测试报错。
- 还没手测：声音听起来对不对（混响、左右）；真的音频设备上建分组和混响。

## 修过的问题

- 给按位置的声音设长的淡出后，相机一动就按 50 ms 重新设音量，淡出变成一下没声；改成按淡变剩下的时间过渡。
- 音量是 NaN 时每帧都给音频线程发命令；音量、声像先清洗。
- 低通开关时干湿交叉淡变，中间会变响；低通改成一直全湿、只调截止频率。
- 震屏时听的人跟着抖，按位置的声音忽大忽小；听的人用不含震屏的相机位置。
- 幽灵追追停停时每次都响；同一只两秒内只响一次。
