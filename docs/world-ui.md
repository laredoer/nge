# 世界里的 UI：血条、气泡、打字机

> 前置：文字（[m5-extensions.md](m5-extensions.md)）、场景节点（[scene-nodes.md](scene-nodes.md)）。

## 目标

现在要在角色头顶放一条血条、让角色说一句话，只能自己拼精灵和文字，每帧在 TSX 里算位置；文字背景框不知道文字有多大，对话也没有一个字一个字出来的效果。

**验收标准**：
- 场景里写 `bars`：一条跟着精灵走的进度条，数值变了平滑过渡。
- 场景里写 `bubbles`：一段带背景框的文字，背景框按文字排版后的大小撑开；可以跟着精灵走，也可以固定在屏幕上（对话框）。
- 文字可以一个字一个字地出来，打完发 `typed` 事件。
- 平台跳跃：角色头顶有血条，失手一次少一格，三格掉光整关重来；每关开始时角色头顶冒一个气泡，打出关卡名，过一会儿消失。

## 做法

### 文字（`nge-text`）

- `Text2d.visible: Option<usize>`：只显示前几个字（按 `char` 数）。排版时整段一起排，后面的字照样占位置、只是透明：打字时不会因为换行跳来跳去，框的大小也一开始就定了。
- 新组件 `TextBox(Vec2)`：渲染器排完版后写回文字框的大小（point；世界文字是世界单位，屏幕文字是屏幕 point），大小变了才写。没有 GPU 时（测试）不写，由用的人自己处理没有的情况。

### 场景（`nge-scene`）

`bars[]`：

| 字段 | 默认 | 说明 |
|---|---|---|
| `id` | 必填 | |
| `value` | 0 | 0 到 1，超出截断；`null`（JS 里的 NaN 序列化出来就是它）和不是有限数的当 0 |
| `follow?` | | 跟着哪个精灵（画面上的位置，含插值和视差）；找不到就藏起来 |
| `x`、`y` | 0 | 跟随时是相对精灵的偏移，不跟随时是世界坐标 |
| `w`、`h` | 32、4 | |
| `color` | `#4ade80` | 填充色 |
| `back` | `#000000a0` | 底色 |
| `z` | 50 | |
| `smooth` | 0.15 | 数值变化的过渡时间（秒），0 是立刻；新建时直接是目标值 |

- 底和填充各一个纯色精灵，填充靠左对齐，宽 = `w × 当前值`，值是 0 时宽也是 0。
- 填充是底的子实体，删掉条时一起删。

`bubbles[]`：

| 字段 | 默认 | 说明 |
|---|---|---|
| `id`、`text` | 必填 | |
| `follow?` | | 跟着哪个精灵；找不到就藏起来 |
| `x`、`y` | 0 | 跟随时相对精灵；`screen` 时是屏幕坐标（左上角原点、y 朝下） |
| `screen` | false | 固定在屏幕上（对话框），不跟相机 |
| `size` | 14 | 字号 |
| `color` | `#ffffff` | 字的颜色 |
| `back` | `#000000b0` | 背景框颜色 |
| `padding` | 6 | 背景框比文字大出来的边 |
| `maxWidth` | 160 | 超过就换行 |
| `typing` | 0 | 每秒出几个字，0 是一下全出来 |
| `font?` | | 同 `texts` |
| `z` | 60 | 背景框的 z；字总画在所有精灵上面 |

- 位置是气泡的底边中点：世界里的气泡往上长，屏幕上的往下长（锚点是顶边中点）。
- 背景框的大小 = `TextBox` + 两倍 `padding`；还没量出来（第一帧、没有 GPU）时背景框是 0。`TextBox` 是上一帧渲染时量的：改了文字的那一帧，框还是旧的大小。
- 条和背景框不受 2D 光照（和字一样），夜里不变暗。
- `w`、`h`、`padding`、`maxWidth` 是负数时当 0。
- 屏幕上的气泡：字是屏幕文字；背景框还是世界里的精灵，每帧按相机把屏幕位置换成世界位置，大小除以缩放。
- 打字：
  - `text` 变了、或者从不打字改成打字，从头打；只改位置、颜色时接着打。
  - `typing` 改成 0 时一下全出来（游戏用它做「点一下跳过」）；文字没变、还没打完的算打完，照样发一次 `typed`，靠它收尾的游戏不会卡住。
  - 打完发一次 `typed { id }`；一开始就不打字的不发。
  - 按 `Time.delta` 走，暂停时停。

系统顺序：放在 `PostUpdate`，在物理和相机之后（跟随的是插值过的位置，屏幕气泡用这一帧的相机）。

### TSX

- `Scene.bars`（`BarNode`）、`Scene.bubbles`（`BubbleNode`），事件 `typed`。

### 示例（平台跳跃）

- 角色头顶一条三格的血条：`value = (3 - 失手) / 3`，失手三次整关重来。
- 每关开始时角色头顶冒一个气泡打出关卡名，打完 1.5 秒后去掉。

## 不做

- 跟着 3D 模型走的条和气泡（`texts` 的 `follow` 已经能跟模型；要时再加）。
- 气泡的小尾巴、圆角、九宫格贴图背景。
- 富文本（一段里不同颜色、字号）。
- 彩色字形（emoji）打字时也藏起来：glyphon 画彩色字形不看颜色的透明度，没打到的 emoji 照样显示。
- 按字素打字：`visible` 按 `char` 数，带组合符号的字、拼起来的 emoji 中间会停一帧。
- 相机旋转时的世界气泡：字总是正的，背景框按世界方向摆，会对不上（场景协议现在不能转 2D 相机）。
- 掉血时的白色残影段。

## 验收

- `nge-text`：`visible` 让后面的字透明、整段照样排版；`TextBox` 的换算（屏幕和世界、缩放）。
- `nge-scene`：
  - 条：位置跟着精灵（含画面插值）、偏移、找不到时藏起来；填充左对齐、宽度按值；值截断和 NaN；平滑过渡、`smooth` 0 立刻、新建时直接到值；删掉时填充一起删。
  - 气泡：背景框按 `TextBox` 撑开、底边在跟随点上；屏幕气泡按相机换算；打字一个字一个字出来、打完发一次 `typed`；只改位置接着打、改文字从头打、`typing` 改 0 全出来；暂停不走。
- 平台跳跃：TSX 测试检查血条的值和气泡。
- 变异检查：值截断和 NaN、新建直接到值、平滑和 `smooth` 0、条和气泡的偏移、不跟随时的世界坐标、找不到时藏起来（条、字、框）、跟画的位置、填充宽度和靠左、填充一起删、框加 padding、没量出来没框、框的底边、屏幕框的换算和缩放、屏幕锚点、屏幕文字、框颜色、不受光照、负数夹到 0、从头打和接着打、暂停不走、只发一次、跳过时补发、按字数、换行宽度；文字层的字数变了重排、按字切、后面透明、框除缩放和密度（缩放 0 不出无穷大）、写回框，改掉都有测试报错。
- 还没手测：血条和气泡在画面上的样子。

## 修过的问题

- 条和背景框会被夜里那关的 2D 光照压暗染色，字却不受光，两者对不上；改成不受光照。
- 用 `typing` 改 0 跳过时不发 `typed`，示例里靠它去掉的气泡就一直不消失；跳过时补发一次。
- 相机缩放写成 0 时文字框除出无穷大；按最小缩放算。
- 负的宽高、`padding` 让背景框比字小、偏移反过来；夹到 0。
- 示例换关时上一关的名字会在新关卡上冒一下，旧的定时器还可能提前去掉新关卡的气泡；换关时先清掉，`typed` 里先取消旧的定时器。
